## 확인할 부분

`read_text_blocks`에는 기존 블록 단위 머리글 판정 외에 다음 코드가 추가됐다.

```python
for run in runs:
    text = " ".join(t for _, t in run)
    if RUNNING_HEAD_RE.match(text):
        continue
```

기존 지시서는 쪽 머리글 판정을 바꾸지 않도록 했다. 제목이나 표 안 줄을 제외한 뒤 남은 구간에 머리글 정규식을 다시 적용하면, 숫자만 있는 본문 구간이 추가로 제외되는지 확인한다.

## 확인 방법

1. 실제 수정 파일에서 이 처리가 필요한 이유와 블록 단위 판정과의 차이를 설명한다.
2. 최소 가상 입력으로 다음 경우를 비교한다.
   - 한 블록에 제목 줄과 표 밖의 숫자만 있는 본문 줄이 함께 있는 경우.
   - 한 블록에 표 안 줄과 표 밖의 숫자만 있는 본문 줄이 함께 있는 경우.
   - 일반 머리글과 쪽 번호 블록인 경우.
3. 실제 수정 함수와, 그 함수에서 위 구간별 필터만 메모리에서 제거한 비교 함수를 사용한다. 파일은 수정하지 않는다. 각 경우의 남은 글을 제시한다.
4. 가상 입력은 동작 차이를 확인하는 기능 검사이며 실제 PDF에서 발생한 손실의 증거는 아니라는 점을 명시한다.
5. 본문 손실 가능성이 확인되면 최소 수정안을 글과 diff 제안으로만 보고하고 종료한다. 가능성이 확인되지 않으면 그 근거를 보고한다.

- 코드 파일, 데이터, 벡터, 캐시를 변경하지 않는다.

- 커밋, 푸시, PR, 병합, 배포는 하지 않는다.
