## 6. 구현할 핵심 A: 실제 작업 행과 머리글 판단

### 6.1 행 분리 책임을 명확히 모은다

현재는 어댑터의 행 분리와 조립 단계의 후보 분리가 둘 다 남아 있다. 이번에는 어느 경로가 행을 나눌지 명확히 정하고, 뒤 단계가 이미 판정한 행을 다시 추측해서 나누지 않게 한다.

판정 결과에는 원래 칸·분리 조각·글 범위·근거·사용한 좌표의 종류·확정 여부를 남긴다. 같은 좌표가 반복됐다는 이유로 이미 분리된 행이라고 추측하기보다 명시적인 분리 기록을 전달한다.

행 분리는 원래 격자·병합·열 역할·숫자와 작업명의 실제 위치를 함께 사용한다. 문단 높이로 추정한 줄 위치만으로 확정하지 않는다. 필요한 경우 기존 PDF 글자층의 실제 위치로 확인한다.

원문 수치와 글을 잃거나, 같은 숫자를 복사해 행 수를 맞추지 않는다. 결정할 수 없는 행은 원래 칸과 대응 후보를 유지하고 보류한다. 기존에 보류된 13표를 모두 정상으로 바꾸는 것이 완료 목표가 아니다.

555쪽의 작업명 줄바꿈과 185쪽 공동 값 처리를 유지한다. 숫자의 글자가 옆 칸으로 이동한 사례를 임의로 보정하지 않는다.

### 6.2 머리글을 근거로 정한다

현재 숫자 없는 표는 첫 행을 머리글로 가정해 본문은 살렸지만 불확실하다. 기존 음영 판정 함수와 실제 표 위치·열 구성 등을 재사용해 판정 근거를 보강한다.

숫자가 들어 있는 머리글과 숫자 없는 본문도 구별한다. 숫자 하나가 나왔다는 이유로 바로 본문이라고 확정하지 않는다. 특히 작은 정의 표와 주석 속 계수 표의 열 이름·단위·값 연결을 유지한다.

판정이 충분하지 않으면 본문은 보존하고 머리글 가정과 보류를 남긴다. 원문 숫자가 없는 자료에 숫자나 단위를 만들어 넣지 않는다.

표·칸 좌표는 실제 PDF 쪽 크기를 기준으로 변환하고 원래 좌표와 원점을 함께 기록한다. 다른 쪽의 가장 높은 글자 좌표가 쪽 높이를 대신하지 않게 한다.

## 7. 구현할 핵심 B: 표 주변과 쪽 경계 연결

### 7.1 앞 쪽의 절과 소제목 이어받기

연속 구간을 문서 순서대로 처리하며 부문·상위 절·하위 절·소제목을 유지한다. 제목이 없다는 이유로 앞 쪽의 다른 절을 무조건 이어받지 않는다. 부문과 제목 경계가 바뀌면 이전 상태를 종료한다.

구간 시작에서 필요한 상위 제목을 확보하지 못했으면 미확정으로 표시한다. 이번 범위 밖의 쪽을 계속 추가해서 찾지 않는다. 결과를 나눠 처리할 때 어떤 문맥 상태를 이어받아야 하는지도 기록한다.

### 7.2 소제목 끝의 기준 연결

원래 소제목 문장과 위치를 보존한다. 기준을 분리했다면 원래 글에서 왔음을 기록한다. 가까운 표가 여러 개거나 적용 범위가 모호하면 후보로 남긴다. 글이 같아도 다른 위치의 기준은 제거하지 않는다.

### 7.3 다음 쪽 주석 연결

앞 쪽 끝의 표와 다음 쪽 첫머리의 주석을 제목 경계·표 위치·주석 표시·문서 순서로 연결한다. 185쪽 6-1-2 표와 186쪽 주석을 포함한 개발 사례를 확인한다.

위치에 따른 소속 후보와 원문에 명시된 연결을 구별한다. 다음 쪽의 다른 절이나 표의 주석을 앞 표에 확정 연결하지 않는다. 다음 쪽을 확인하지 못했으면 근거가 완결됐다고 표시하지 않는다.

### 7.4 이어지는 표 연결

이어짐 표시·같은 절·열 구성·병합과 작업 조건 등을 근거로 표 조각의 관계를 기록한다. 열 이름이 같다는 이유만으로 다른 표를 합치지 않는다.

각 쪽의 원래 표 식별자·칸·좌표·내용을 유지한다. 논리적으로 같은 표라는 관계와 원래 표 조각을 따로 보관한다. 여러 쪽의 자료를 한 쪽의 출처로 표시하지 않는다.

기존 `chunk.py`는 변경하지 않는다. 여러 쪽 표의 연결은 파싱 보관 결과와 연결 자료에 남기고, 기존 청킹에 넘길 때 각 원문 표 조각의 출처가 유지되게 한다. 새로운 청킹 분할 설계를 이번 작업에 섞지 않는다.

개발 구간 안에서 실제 이어지는 표 사례를 확보하지 못하면 기존 출력의 이어짐 표시 사례를 확인하되, 필요한 원문 쪽이 범위 밖이면 미확인으로 보고한다. 실제 사례가 없는데 가상 입력만으로 원문 처리가 완료됐다고 쓰지 않는다.

## 9. 확인은 한 보고로 묶는다
