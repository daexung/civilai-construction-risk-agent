# 파싱 개발 이력과 결과 수치

기록일: 2026-10-11. 중간 작업 폴더를 정리한 뒤에도 개발 순서, 수정 이유, 결과 수치, 확인 범위, 남은 문제를 이어받기 위한 문서다.

현재 실행 위치는 `experiments/parsing-final`이다. 아래 날짜별 폴더와 깃 상태는 정리 전의 개발 이력이다. 정리 후 보존 위치와 확인 결과는 [정리 결과](../reviews/parsing-cleanup-result-2026-10-11.md)를 읽는다.

이 문서는 기존 보고서와 저장된 비교 자료를 정리한 기록이다. 초기 이력 작성에서는 파싱이나 검사를 다시 실행하지 않았다. 이후 최종본 정리에서 재실행한 결과는 순서 11과 별도 정리 보고서에 기록했다. 아래 날짜는 보고서 날짜이며, 같은 날짜의 작업은 선후 관계로 나열했다. 확인되지 않은 시작 시각이나 작업 시간을 만들지 않았다.

## 1. 전체 목표와 현재 위치

전체 목표는 표준품셈을 근거로 적용 조건과 가정을 보여 주는 견적 서비스와 실무용 Excel이다. 파싱은 그 입력을 준비하는 단계다.

진행 흐름은 원문 PDF → 추출과 원문 구조 보관 → 청킹 → 임베딩과 검색 → 근거를 사용한 설명·견적과 서비스 확인이다. 추출된 글을 보존한 것과 계산 의미를 확정한 것은 구분한다.

현재는 일반 파싱 코드의 확인된 표·본문 전달 결함을 수정한 시점이다. 현재 결과를 기준으로 일반 파싱 코드 수정을 마무리하고 청킹으로 넘어가는 방향을 권고했다. 수식과 설명 소속의 개별 교정은 남아 있다. 전체 문서의 모든 의미가 검증되었거나, 견적 계산과 운영 적용이 완료됐다는 뜻은 아니다.

## 7. 중간 자료를 정리할 때 보존할 것

개발 이력 문서만 남기고 필수 입력과 교정 근거를 지우지 않는다. 파일 정리는 아직 실행하지 않았다.

| 종류 | 보존 원칙 |
|---|---|
| 최종 코드·실행 방법 | 최종본 한 벌을 기준으로 보존 |
| 교정 자료 | `out/corrections.json`, `row_mappings.json`, `completeness.json`, `reviewed_tables.json`, `diagram_tables.json` 등 실제 실행 의존 자료 보존 |
| 원문과 원시 출력·부문 정보 | 재생성 필수 입력으로 별도 보존. 원시 자료는 현재 `parsing-full-review-2026-10-11/out/raw/`를 읽음 |
| 기존 결과 비교 기준 | 본문 수정 직전 기준 `baseline/before_fix/`와 현재 검증기가 읽는 이전 자료를 먼저 분리·보존 |
| 검증과 교정 근거 | 필요한 확인 코드, 핵심 원문 대조 근거, 본문 복구·정상 제외 목록과 버전 정보 보존 |
| 최종 지표와 보고서 | 이 문서·수치 보존본·관련 최종 보고서를 깃 저장 대상으로 정리 |
| 중간 전체 출력·중복 백업·임시 그림 | 의존 관계와 근거 보존을 확인한 뒤 삭제 후보로 분류 |

최신 `verify_resume.py`는 `parsing-recovered-completeness-2026-10-11`의 결과·교정 자료도 읽는다. `body_text_audit.py`는 최신 폴더의 `baseline/before_fix/out`을 읽는다. 따라서 이전 폴더와 백업을 바로 통째로 삭제하면 검증이 중단된다. 필요한 비교 기준을 모으고 경로를 정리한 뒤 실행·검증 가능한지 확인해야 한다.

2026-10-11 정리 전 확인한 파싱 작업 폴더 7개는 2,868파일, 약 1,334MB다. 최신 폴더는 약 342.5MB이며 수정 전 백업 162.2MB, 현재 출력 168.4MB가 큰 비중을 차지했다. 이 수치는 당시 파일 상태이며, 삭제 가능 용량을 뜻하지 않는다.

## 8. 깃과 운영 상태

2026-10-11 이력 작성 전 확인한 원본 브랜치는 `claude/multi-work-estimate`, 마지막 커밋은 `ad38869`(10월 7일)다. 파싱 작업 폴더와 관련 문서는 아직 추적하지 않는 파일이었다. 이번 이력 문서 작성도 커밋·푸시를 수행하지 않았다.

실제 개선 코드는 별도 실험 폴더에 있다. 원본 운영 `pipeline` 교체, 최신 전체 청킹·임베딩, 운영 데이터 반영, 서비스 개선 확인, 배포는 이 기록 기준 미완료다.
