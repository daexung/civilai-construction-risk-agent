## B0 새 노드 설계 (본문)

### 결정 (2026-11-07)

- 사용자 두 부류: **빠른 질문**(무료, 진입) / **견적 만들기**(유료)
- 금액까지 무료, **원가계산서·Excel은 유료**
- 화면: 탭 3개 💬 빠른 질문 / 📋 견적 만들기 / 📁 내 견적. 질문 중 견적 이야기가 나오면 "이 내용으로 견적 만들기 →" 버튼으로 문맥을 들고 이동
- 견적 탭 모양: **(가) 대화 중심** — 왼쪽 대화, 오른쪽 결과표. 표의 조건 칸을 눌러 직접 수정 가능하게 해서 양식형 장점도 가져감
- "먼저 답하고 필요할 때만 묻기": 대표값으로 먼저 계산해 표를 보여주고, 사용자가 표에서 고침
- 진행: 백엔드(B1~B4) 먼저, 프론트(F) 다음. 기능 스위치 뒤 작은 PR, 실패하면 끄고 v0.2.0으로 복귀

### 결정 2 (2026-11-07)

- **흐름**: ① 빠른 질문(근거+대표값 답, [이 내용으로 견적 만들기 →]) → ② 견적 탭(대표값으로 먼저 계산, 가정 조건을 노란색 표시, 표 클릭·대화로 수정, 즉시 재계산, 금액까지 무료) → ③ 원가계산서·Excel 🔒 → 구독 안내 → ④ 내 견적(저장 목록, 열면 ②로 이어서)
