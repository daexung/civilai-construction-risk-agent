# 계산 명세 형식

`agent/rules/specs/<부문>/<절-작업>.json` 한 파일 = 한 절(부문+절 번호)의 한 작업에 대한 계산 명세. 완성 예시: `agent/rules/specs/common/6-1-4_pump.json`. 이 문서는 강한 모델이 초안을 쓸 때 지시문에 그대로 들어가므로, 여기 없는 필드는 만들지 말고 여기 있는 값만 쓴다.

## 최상위 필드

| 필드 | 뜻 | 값 |
|---|---|---|
| `id` | 명세 고유 id | `"2026-정오표1차/<부문>/<절 번호>/<작업 이름>"` (예: `"2026-정오표1차/공통/6-1-4/펌프차타설"`) |
| `edition` | 품셈 판 | 항상 `"2026-정오표1차"` |
| `division` | 부문 | 예: `"공통"` (page_map의 "부문" 접미사는 뗀다) |
| `section_no` | 절 번호 | 예: `"6-1-4"` (세 자리: 장-절-소절) |
| `title` | 절 제목 | PDF 절 표제 그대로 (년도 보완 표기 등은 빼도 됨) |
| `work` | 이 명세가 다루는 작업 범위 | 예: `"기본 타설 품량"` — 절 전체가 아니라 이 명세가 계산하는 범위만 |
| `review` | 검토 상태 | AI 초안은 항상 `"AI 초안 · 검토 전"` (사람이 검토하면 `"미완료"`→최종은 별도 값) |
| `source_pages` | 근거 PDF 쪽(정수 배열) | 예: `[186, 187]` |
| `inputs` | 계산에 필요한 사용자 입력 목록 | 아래 참고 |
| `tables` | 원문 표를 그대로 옮긴 값 | 아래 참고 |
| `crew_rules` | 조건부 인원 가감 | 아래 참고 |
| `quantity_model` | 계산 방식과 그 파라미터 | 아래 참고 |
| `blocked` | 계산을 보류해야 하는 조건 | 아래 참고 |
| `not_calculated` | 이 명세가 다루지 않는 항목(고지용) | 아래 참고 |
| `supply_rules` | 관급/사급 등 재료 공급 구분 처리 | 아래 참고, 없으면 `[]` |
| `cost_rules` | 노무비 기준 경비·재료비 비율 규칙 | 아래 참고, 없으면 `[]` |

## `inputs[]`

사용자에게 되물어 받는 값 하나당 원소 하나.

| 필드 | 뜻 |
|---|---|
| `name` | 코드에서 쓰는 입력 이름(영문 snake_case) |
| `type` | `enum` \| `boolean` \| `nonnegative_integer` \| `positive_rational` 중 하나 |
| `allowed_values` | `enum`/`boolean`은 허용값 배열, 그 외는 사람이 읽는 범위 설명 문자열 |
| `unit` | 단위 문자열, 없으면 `null` |
| `required` | 항상 `true`(선택 입력은 아직 없음) |
| `ask` | 사용자에게 되물을 한국어 질문 |
| `source` | 이 입력을 어디서 근거로 삼았는지(쪽·항목) 서술 |
| `synonyms` | (선택) `enum` 값별 동의어 배열 — 사용자가 다르게 표현해도 매칭하기 위함 |
| `decision_table` | (선택) 이 입력을 판정하는 데 쓰는 표의 `tables[].id` — 되물을 때 그 표를 같이 보여줌 |
| `machine_codes` | (선택) `enum` 값별 장비 코드 |
| `excluded` | (선택) 허용값에서 뺀 값과 그 이유 |

`type` 선택 기준: 이산 선택지는 `enum`, 예/아니오는 `boolean`, 정확히 셀 수 있는 개수는 `nonnegative_integer`, 물량처럼 소수 가능한 양수는 `positive_rational`.

## `tables[]`

원문 표를 원문 숫자 그대로(문자열) 옮긴다. 계산하지 않는다.

| 필드 | 뜻 |
|---|---|
| `id` | 표 조각의 `table_id`와 일치(예: `"p187-t0"`) — **원문 조각에 없는 id를 지어내지 않는다** |
| `role` | 이 표가 무엇을 담는지 한 줄 |
| `source` | PDF 쪽·표 제목 |
| `unit` | (선택) 표 값의 단위 |
| `values` | 중첩 객체. 보통 `{행 이름: {열 이름: "값"}}`. 값은 반드시 문자열(정확한 분수/소수 보존, 부동소수점 금지) |
| `cite` | `{"table_id": id}` |

행·열 이름은 원문 표기를 그대로 쓴다(예: `"무근"`, `"8~12㎝"`). 계수표처럼 열이 하나뿐이면 `{"f1": {행: "값"}}`처럼 임의의 계수 이름을 행으로 둔 한 겹 중첩을 쓴다(예시의 `p187-t1` 참고).

## `crew_rules[]`

조건에 따라 인원을 가감하는 규칙.

| 필드 | 뜻 |
|---|---|
| `when` | `{입력 이름: 값}` — 이 조건이 모두 맞으면 적용 |
| `when_text` | `when`을 사람이 읽는 문장으로 |
| `change` | `{직종 이름: "+1"}`처럼 가감할 인원(문자열, 부호 포함) |
| `source` | 근거 쪽·비고 |
| `cite` | 인용 키(아래 "인용 키" 참고) |

## `quantity_model`

계산 방식 하나. `name`으로 어떤 계산 함수를 쓸지 고른다.

### `adjusted_daily_crew` (구현됨 — `agent/tools/calc/daily_crew.py`)

일당 작업조형: 기준 일일시공량에 계수를 곱해 조정 후, 물량 ÷ 일당시공량 = 작업일수를 구하고, 직종별 인원 × 작업일수로 인·일을 낸다. `p186-t1`(6-1-4)처럼 "구조물별/직종별 인원 + 장비 대수" 표와 "기준 일일시공량 × 계수" 표가 있는 절에 쓴다.

```json
"quantity_model": {
  "name": "adjusted_daily_crew",
  "params": {
    "base_output": {"table": "표id", "row_input": "입력이름", "column_input": "입력이름"},
    "coefficients": [{"table": "표id", "row": "행이름(표 안의 고정값)", "input": "입력이름"}],
    "crew": {"table": "표id", "column_input": "입력이름", "trades": ["직종1", "직종2"],
             "rate_codes": {"직종1": "단가코드"}},
    "equipment": {"name": "장비이름", "table": "표id", "unit": "대·일", "machine_code_input": "입력이름",
                  "operator_rate_code": "단가코드"},
    "quantity_input": "물량 입력 이름"
  },
  "steps": ["계산 순서를 사람이 읽는 문장으로, 한 줄에 한 단계"],
  "source": "이 계산 전체의 근거 쪽",
  "rounding": "총 투입량은 정확한 유리수로 보존; 단위당 품은 공통 1-2-8·1-2-1 기본 자릿수 적용"
}
```

`base_output`/`coefficients`의 `table`은 `tables[]`의 `id`를 가리킨다. `row`/`column`은 표의 실제 행·열 이름과 정확히 같아야 계산이 그 표 셀을 찾는다.

### `per_unit` (미구현 — 계산 함수는 앞으로 만든다. 초안에는 이 구조로 쓴다)

일당 작업조가 아니라 **단위당 품**이 직접 표에 있는 절(예: 단위 ㎡·본·개소당 인·일이 표에 바로 적힌 경우)에 쓴다. 계산은 `단위당 품 × 물량`이 뼈대이고, 할증률과 원문 [주] 보정을 더한다.

```json
"quantity_model": {
  "name": "per_unit",
  "params": {
    "unit_rate_table": {"table": "표id", "row_input": "입력이름 또는 고정 행이름",
                         "column_input": "입력이름 또는 고정 열이름", "trades": ["직종1"]},
    "quantity_input": "물량 입력 이름",
    "surcharges": [
      {"when": {"입력이름": "값"}, "rate": "0.1", "applies_to": ["직종1"], "source": "근거"}
    ],
    "note_adjustments": [
      {"when": {"입력이름": "값"}, "change": "표현(가산/승수 등, [주] 원문 그대로 서술)", "source": "근거"}
    ]
  },
  "steps": ["단위당 품을 표에서 고른다.", "물량을 곱해 총 품을 구한다.",
            "surcharges/note_adjustments를 원문 순서대로 적용한다."],
  "source": "근거 쪽",
  "rounding": "동일 원칙(1-2-8·1-2-1)"
}
```

`surcharges`/`note_adjustments`는 원문에 있을 때만 채운다. 계산 함수가 아직 없으므로 **이 절을 계산에 바로 쓰지 않는다** — 초안 작성 시 `calc_type`을 `"per_unit"`으로 표시해 사람이 계산 함수를 만들 대상을 구분하게 한다.

### `rate` / `lookup_only` / `not_calculable`

계산 함수가 아직 없는 나머지 경우를 분류만 한다(`quantity_model`을 억지로 채우지 않는다. `quantity_model.name`에 분류만 적고 `params`는 `{}`, `steps`에 사람이 보면 알 근거만 남긴다):

- `rate`: 물량에 비율(%)만 곱하는 계산(예: 경비율 적용 자체가 본 작업인 경우)
- `lookup_only`: 조건에 따라 표에서 값 하나를 찾아 보여주기만 하면 되는 경우(계산식 없음)
- `not_calculable`: 원문이 입력만으로 자동 계산할 만큼 명확하지 않거나, 표가 없거나, 판단이 크게 필요한 경우

## `blocked[]`

계산을 하지 않고 사유를 보여줘야 하는 조건.

| 필드 | 뜻 |
|---|---|
| `condition` | 사람이 읽는 조건 설명 |
| `blocked_if` | (선택) `{"input": 입력이름, "op": ">"\|">="\|"<"\|"<="\|"=="\|"!=", "value": 값}` — 기계로 판정 가능하면 채움 |
| `reason` | 왜 계산할 수 없는지 |
| `source` | 근거 쪽 |
| `cite` | 인용 키(배열 가능) |

## `not_calculated[]`

이 명세의 계산 범위 밖이라 결과에 "미산정"으로 안내할 항목.

| 필드 | 뜻 |
|---|---|
| `item` | 항목 이름 |
| `source` | 근거 쪽 |
| `cite` | 인용 키 |

## `supply_rules[]`

관급/사급처럼 재료 공급 주체에 따라 원가 처리가 달라지는 항목.

| 필드 | 뜻 |
|---|---|
| `item` | 재료 이름 |
| `input` | 이 판단에 쓰는 입력 이름 |
| `category` | `"재료비"` 등 |
| `when` | `{입력값: {"status": "제외"\|"미산정"\|"산정", "reason": "..."}}` |
| `source` | 근거 |
| `cite` | 인용 키 |

## `cost_rules[]`

노무비 합계를 기준으로 한 비율 경비·재료비.

| 필드 | 뜻 |
|---|---|
| `name` | 항목 이름 |
| `category` | `"경비"`\|`"재료비"` 등 |
| `base` | 항상 `"labor_subtotal"`(현재 유일하게 지원하는 기준) |
| `rate` | 비율(문자열, 예: `"0.05"`) |
| `cite` | 인용 키 |

## 인용 키(`cite`)

숫자·규칙마다 원문 근거를 남긴다. 두 형식뿐이다.

- 표 인용: `{"table_id": "표id"}` (필요하면 `"row"`, `"column"`, `"value"` 추가)
- 줄글 인용: `{"section_no": "6-1-4", "subsection_no": "2", "marker": "①"}` — `marker`는 원문의 ①②…, ※, "가."~"하." 중 하나. 절 본문 첫 줄이면 `"marker": "본문"`

`cite`가 여러 근거를 가리키면 배열로 쓴다.
