# PDF 185쪽 육안 검토에서 확인한 평가 항목

사용자 검토일: 2026-10-10. 사용자 원문 대조와 기준 커밋의 원문 표 이미지 대조를 바탕으로 기록한다. 운영 코드와 데이터는 수정하지 않았다.

## 확인 내용

1. 비고 안의 작은 표가 한 문장으로 합쳐졌다. ‘인력운반 타설’과 ‘장비사용 타설’ 각각의 설명을 구분하는 관계가 필요하다. 글자가 전부 있는지뿐 아니라 중첩 표의 행과 설명이 올바르게 연결되는지 평가한다.
2. 장비사용 타설의 시공량 63·55는 원문의 콘크리트공·보통인부·굴착기 행에 걸친 공유 칸이다. 기존 청크는 두 직종에 값을 쓰고 굴착기 행에서는 누락한다. 출력이 없는 굴착기 행을 빈 값이나 적용되지 않는 값으로 해석하면 안 된다. 공유 값을 연결하는 방식은 값 복제 또는 공유 칸 참조 등일 수 있지만, 작업조 전체에 적용됨을 알 수 있어야 한다. 개별 자원마다 별개의 시공량이나 별도 작업으로 중복 계산하면 안 된다.
3. 6-1-1 주석은 ‘미장공에 의한 표면 마무리가 필요한 경우’ 6-1-3을 따르도록 한다. 원본 참조 문구·출발 절·대상 부문과 절·적용 조건·주석 위치를 보존하는지 평가한다. 표면 마무리를 모든 타설 견적에 자동 추가하지 않는다. 부문이 다른 동일 절 번호도 구분한다. 큰 그래프 시스템 도입을 요구하는 항목은 아니다.
4. 시제품의 반복된 추정 표시와 내부 행 번호는 사람이 비교하기 어렵다. 원문·읽기 쉬운 출력·검사 정보를 분리한다. 추정 여부는 추출 경위를 뜻하며 계산 정확도나 숫자 생성 여부를 보증하지 않는다.
5. 시제품은 원문의 ‘인력운반 타설’ 병합 라벨을 ‘인력운반’과 ‘타 설’로 분리했다. 이 표는 정상 표 회귀 대조군으로 유지한다.

## 비교에 반영할 항목

- 중첩 표의 유형과 설명 대응
- 병합 공유 값의 적용 범위와 중복 계산 방지
- 조건이 붙은 절 참조의 원문 보존과 연결
- 사람이 검토할 수 있는 표시

파서가 직접 보존한 정보와 후처리에서 추가한 연결은 구분해 채점한다. 이 기록만으로 모든 원문 숫자와 계산 규칙을 검토 완료로 표시하지 않는다. 실제 계산기 오류 여부도 별도 확인 대상이다.
