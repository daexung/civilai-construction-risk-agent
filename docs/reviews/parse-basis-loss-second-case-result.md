# 195쪽 6-3-5 맨홀 거푸집 표 산출 기준 보존 확인 (두 번째 사례)

**같은 방법으로 195쪽에서도 기준이 보존됐다.**

이번 결과는 186쪽과 195쪽, 두 개발 사례의 확인이며 전체 품셈에 대한 검증이 아니다.

## 입력과 방법

- 기준 코드: `baf186f`의 `pipeline/parse.py:78-104` (`read_text_blocks`). 블록 중심이 표 안(±2pt 허용)이면 블록 전체를 버린다.
- 표 좌표: `experiments/table_census/results/tables.json`의 `p195-t3` = 68.0 · 589.6 · 543.4 · 667.2 (섹션 6-3-5). 같은 쪽 `p195-t0`~`t2`도 기존 방식처럼 표 좌표로 함께 넣었다. 새 표 추출은 하지 않았다.
- 글자층: PDF 195쪽(`2026_건설공사표준품셈_원문_정오표1차_반영.pdf`)의 기존 글자층(`get_text("blocks")`, `get_text("dict")`)만 읽었다.
- 시제품: 186쪽 결과 문서에 적힌 방법(블록 대신 줄 단위, 줄 중심이 표 안이면 제외, 허용 ±2pt, 머리글·절 제목 필터 동일)을 **메모리에서 그대로 재현**했다. 저장소에 구현 파일은 없다. 방법·허용 범위는 변경하지 않았다.
- 새 규칙을 만들거나 고쳐 다시 돌리지 않았다.
