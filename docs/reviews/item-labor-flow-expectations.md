# 3단계 항목별 품 흐름 기대값

검사 실행 전에 고정한 기대값입니다. 검색 후보는 실제 계산 명세의 절 번호를 사용한 모의 검색 입력이고, 외부 모델·임베딩·운영 API·DB는 부르지 않습니다.

| 시나리오 | 기대 |
|---|---|
| 수성페인트 롤러칠 2회 벽면 100㎡ + 실내 방수모르타르 10㎜ 바닥 20㎡ | 도장 명세의 ㎡당 0.012/0.002에 횟수 2와 100㎡ 적용 → 도장공 2.4, 보통인부 0.4. 방수모르타르 10㎜ 이하 명세의 ㎡당 0.047/0.035와 20㎡ 적용 → 미장공 0.94, 보통인부 0.70. 각 명세의 표 근거를 노출 |
| 도장 100㎡ + 방수 20㎡ 범위 확인 | 안정된 별도 ID 두 개, 원래 물량/근거 유지. 확인 전 검색·계산 금지 |
| 각 항목에 서로 다른 명세 후보 주입 | 항목별 후보·선택·질문·조건·품 결과 분리. 한 항목 답은 다른 항목에 적용 안 됨 |
| 내부 도장 100㎡ + 외부 도장 20㎡ | 같은 공종이어도 별도 ID와 독립 세션, 양·답 섞이지 않음 |
| 조적벽에 도장 | 도장 한 항목만 생성, 조적벽은 바탕 근거로 유지 |
| 도장 명세 계산 가능, 다른 작업에 명세가 없는 모의 후보 | 도장은 기존 계산 결과 유지, 해당 작업은 `UNSUPPORTED` / 미산정 범위로 표시 |
| 도장에 조건이 필요하고 방수는 완료 | 항목별 pending 질문/완료 상태 동시 보존 |
| 도장 한 항목 물량 또는 조건 편집 | 해당 항목 확인·결과 무효화, 항목 재확인 후에만 재계산. 다른 항목 결과/조건 유지 |
| 항목 정렬 순서 변경 | item ID와 답 연결 유지 |
| 오래되거나 다른 항목 질문 ID/버전 답변 | 거부, 상태 변경 없음 |
| 범위 미확정 또는 확인 뒤 변경된 범위 | 항목 검색·계산 시작 거부 |
| 제외 항목의 답변 시도 | 거부, 시공 항목으로 만들지 않음 |
| 시험 옵션 꺼짐 | 모든 시험 API 경로가 404 |
| 기존 단일 공종 도구 회귀 | 결과 변화 없음 |
