# Codex 사용량 조사 — 2026-10-16

## 조사 범위
이 검토 대화와 구현용 루나 대화 두 개만 확인했다. 대화 본문이나 비밀값은 보고서에 옮기지 않았다. 로컬 세션 기록의 token_count 누적값 차이를 한국시간 2026-10-16으로 집계했다. 조사 시점 이후 사용은 포함하지 않는다. 갱신 건수는 실제 외부 API 요청 수와 동일하다고 보장하지 않는다.

| 구분 | 검토 대화 | 구현용 루나 |

| 기록 모델 | gpt-6.1-sol | gpt-6-luna |

캐시 입력은 전체 입력에 포함된다. 추론 출력도 전체 출력에 포함되므로 다시 더하지 않는다. 반복해서 읽은 문맥도 입력 집계에 들어가며, 위 숫자는 새 글을 그만큼 작성했다는 뜻이 아니다.

## 확인한 원인
- 오래 이어진 두 대화의 큰 문맥을 여러 도구 왕복에서 다시 처리했다.
- 검토 대화도 수백 번의 사용량 갱신이 있었다. 구현만 루나로 맡겨도 검토 쪽 사용량이 줄어드는 구조가 아니었다.
- 공식 표준 단가에서 Sol은 Luna보다 새 입력과 출력이 20배, 캐시 입력이 10배다. 비슷한 입력량이어도 검토 쪽 비용 영향이 크다.
- 구현 과정의 환경 문제, 긴 오류 출력, 반복 검토와 재실행이 왕복을 늘렸다. 특정 오류에 얼마가 청구됐는지는 이 집계만으로 분리할 수 없다.
- 대기 시간 자체를 토큰 사용으로 세지 않았다. 모델이 결과를 읽고 판단하는 왕복이 사용을 늘린다.

## 즉시 바꾼 진행 방식
구현용 루나에 범위를 현재 중복 오류 수정과 집중 검사, 서버 재시작으로 제한했다. 추가 기능, Docker 추가 조사, 새 모델과 임베딩 호출은 멈췄다. root는 해당 검사 한 번과 화면 확인만 수행한다. 이후 작업은 짧은 인계와 필요한 파일만 받는 별도 작업으로 나누고, 검토를 완료 시점에 모은다. 현재 모델이나 계정 설정은 임의로 바꾸지 않았다.
