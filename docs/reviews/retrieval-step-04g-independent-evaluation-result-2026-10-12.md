# 검색 4g단계 결과: 현재 근거 검색 경로의 새 질문 20개 평가

작성일: 2026-10-12. 4f까지 만든 검색·선택·검증 경로를 **코드·설정 수정 없이** 새 질문 20개로 평가했다. 질문과 기대값은 원문 DB와 원문 PDF 쪽을 읽어 실행 전에 고정했고, 검색부터 최종 문맥·상태까지 실제 경로를 처음부터 실행했다. 결과를 보고 코드·프롬프트·질문을 고치지 않았다. 서비스 연결·원격 연결·코드 개선·커밋·푸시·배포는 하지 않았다.

> 이 문서의 비율은 **20문 작은 표본**의 결과이며 전체 문서나 전체 사용자 질문의 정확도가 아니다.

## 결론: 일부 유형만 시험 가능

로컬 서비스의 **제한된 시험 연결은 일부 유형에 한해 가능**하다. 전체 시험 연결 준비는 아니다.

| 구분 | 근거 |
|---|---|
| 지원 가능한 유형 | 규격·단위가 명시된 값·품 질문(6/6 문맥에 필수 표), 제외·참조 규칙 질문(2/2), 범위가 명확한 공종 목록(11, 12, 13: 필수 절 22/22), 자료 없음(4/4, 정상·확인용 문맥 0, 반복 3회 안정), 번호·범위 모호(2/2, 호출 0) |
| 제외·확인 필요한 유형 | ① 질문에 의존 명사·외래어 명사가 낀 경우(`짜리`, `호퍼스케일`): 낱말 부재로 잘못 보류되고 **대상 대조가 필수 표를 제외**한 사례 있음(G10) ② 소속 미확정 자료의 필수 표 전달이 반복마다 달랐음(G09) ③ 범위가 모호한 목록의 완전성 표시가 모순(G14) |
| 목표 대비 | 필수 근거 포함률 목표 95%는 **미달**(조각 11/13 = 84.6%). 금지 주·문맥 혼입 0, 중요한 잘못된 표·수치·조건의 정상 전달 0, 정상 질문 거부 0, 미확정 승격 0은 충족 |

시험 연결 전에 위 제외 유형을 막거나, 대상 대조 경로를 끄거나 보완해야 한다(수정은 이번 범위가 아니다). 계산·운영·배포 승인이 아니다.

## 7. 새로 발견한 문제 (코드 수정 없이 기록)

1. **부재 대상 탐지가 의존 명사·외래어 명사를 잘못 잡는다(독립 평가에서 처음 드러남).** `규격 400㎜짜리`의 `짜리`(G03·G10)와 외래어 `호퍼스케일`이 끝 음절 `일`을 어미로 떼 `호퍼스케`로 잘린 것(G09)이 원문에 없는 "대상 낱말"로 판정됐다. 4f에서 닫힌 어미 부류의 문법으로 일반화했지만 이 두 유형은 처리하지 못했다. 결과: G03·G10 불필요 보류, G09에서 확인용 강등.
2. **대상 대조 경로의 위험.** 이 경로는 부재 낱말이 있으면 정상 질문에서도 호출된다.
   - G10: 모델이 정답 표를 `different`(`1.5m 이하까지의 표 기준만`)로 판정해 **필수 표가 문맥에서 제외**됐다.
   - G03: 모델은 정답이 있는 표의 7개 행을 모두 `different`(`철판 두께와 규격이 일치하지 않는다`)로 잘못 판정했다. **후보 식별자 형식(`C04.1`)이 별칭(`C04`)과 달라 코드가 판정을 쓰지 않아** 제외되지 않았다. 형식이 맞았다면 정답 표가 제외되어 정상 질문이 `not_found`가 됐을 것이다.
   - N19(4f)에서는 같은 경로가 의도대로 작동했다. 이 경로의 판정 신뢰도는 낮고 표본이 작다.
3. **소속 미확정 자료의 필수 표 전달이 반복마다 다르다**(G09). 보류는 안정했으나 같은 질문에서 표가 누락되거나 확인용으로 있다.
4. **범위 모호 목록의 완전성 표시 모순**(G14).
5. **관측하지 못한 한계**: G07은 제외 의미는 있으나 부정 표지(`않`·`없이` 등)가 없어 4f의 부정 조건 보류 경로를 시험하지 못했다. 부정 과다 보류, 부재 대상 탐지 누락(fail-open), 목록 과다 포함, 모델 변동은 사라졌다고 할 수 없다.
