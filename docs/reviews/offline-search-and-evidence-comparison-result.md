## 1. 사용자 질문 5종: 가·나·다가 어떻게 달라졌나

- **가** = 기존 청크를 그대로 키워드 검색 (현재 검색 표현)
- **나** = 질문 의도에 맞춰 공종 목록 / 규칙 설명 / 표·작업 조건 표현 중 하나를 키워드 검색 (**순위는 다의 순위와 같다**)

## 3. 다에서 근거 상태가 어떻게 전달됐나

세 가지 구분(지시서 4장)을 적용했다.

| 분류 | 정의 | 길이 한도에서 |
|---|---|---|
| 필수 | 매칭된 청크, 그 표의 기준·단위, 표 바로 아래 주석, 그 안의 조건부 참조(확정이면 실제 원문) | 먼저 담는다. 못 담으면 "필수 근거 미완료" |
| **적용 범위 미확정** | 같은 절의 다른 줄글, 상위 절(6-1 등) 일반 규정 | 선택으로 버리지 않는다. 담지 못하면 열린 항목에 "생략된 적용 범위 미확정 규정 N건"으로 남기고 계산 근거 완성으로 보지 않는다 |
| 선택 | 같은 절의 다른 표 | 길이 한도에서 먼저 빠짐 |

- **전달 완료**와 **적용 범위 확인 완료**는 따로 표시한다. 20문 중 나의 1위 공종 기준으로 "필수 전달 완료" 18, "필수 근거 미완료" 2(Q07의 1위 8-5-4, Q15), "적용 범위 확인 완료" 6(Q07·Q08·Q14·Q15·Q16·Q19 — 해당 절·상위 절에 미확정 규정이 없는 경우뿐이며, 이 중 Q08·Q19는 1위 공종 자체가 틀려 의미가 없다).
- 필수 근거 미완료 사례: Q15(한쪽 레일) — 매칭 표 청크가 2,130자라 표 아래 [주](246자)를 한도(2,400자) 안에 담지 못해 `길이 한도로 빠진 필수 근거 1건`이 열린 항목에 남았다. 이 질문의 답("65%")은 표 안 비고에 있어 근거 글자 확인은 O였다.
- 조건부 참조(나의 1위 공종 기준): Q17(소형구조물)·Q18(소량 타설)의 필수 청크 안 "[공통부문] 6-1-3 표면 마무리" 참조를 문서·부문·번호·제목으로 **확정하고 실제 원문(186쪽 제목·(100㎡당)·표·주석)을 묶음에 전달**했다. 2·3위 공종에 붙은 근거에서도 확정·전달이 3건 있었지만 모두 기대 공종이 아닌 후보의 참조다(Q16 건축 6-4-1 → 9-1-1·6-2-1, Q09 토목 3-2-5 → 3-2-1).
- 참조 문장이 다른 절의 **주석 하나**를 가리키는 경우(Q09의 토목 3-2-5 "‘[토목부문] 3-2-4 … [주] ④’")는 제목이 일치하지 않아 **후보로만** 남고 내용은 전달하지 않았다. 절 단위 조회만 지원하며 "특정 주석 위치 조회"는 지원하지 않는다.

### 3-1. 입력 자료의 결함: 기준 표기 누락 (검색 성공과 분리)

`(100㎡당)` 누락은 검색 개선으로 고쳐진 값이 아니다. 기존 청크의 basis가 비어 있어 **PDF 글자층에서 보완한 값**이며, 근거에는 "기존 입력 자료 결함, PDF 글자층 확인"으로 표시했다.

| 확인 | 결과 |
|---|---|
| 이번 20문의 근거 묶음에 들어온 표 중 기준 표기가 비었는데 PDF에는 있는 표 | 3개: `p186-t0` (100㎡당), `p645-t0` (㎡당), `p195-t3` (개소당). 원문 그림으로 3개 모두 확인 |
| 전체 표 청크 2,304개 중 basis가 없고 본문에도 "기준" 줄이 없는 표 | 1,434개 |
| 그중 바로 위 PDF 글자층에 `(…당)` 줄이 있는 표(휴리스틱) | **183개**. 표본 3개만 눈으로 확인했고 나머지는 미검증 |

183개는 모두 사실이라고 단정하지 않는다. 다만 이 기준 표기 없이는 "일당/㎡당/m당" 의미가 전달되지 않으므로 운영 입력 자료의 점검 항목으로 둔다.

### 3-2. 다에서 되지 않은 것

- 기존 청크는 185쪽 장비사용 타설의 공동 시공량(63/55)을 줄마다 반복해 두고 **공동값 표시가 없다.** 이전 단계의 ODL 보관 구조는 한 칸으로 보존했지만, 이번 비교는 전체 청크를 같은 입력으로 쓰도록 ODL 12쪽을 쓰지 않았다. ODL 연결은 이전 결과 문서의 사례로만 본다.
- 5개 표의 행·열 대응이나 계산 사용 가능 여부는 이번에도 승인하지 않았다. 다의 계산 사용은 "승인 아님"이다.

## 7. 다음 결정

1. **검색 설계 유지 여부:** 세 표현을 따로 두는 구조는 유지해도 좋다. 다만 이번 결과에서 **순위 개선 효과는 확인되지 않았다**(공종 적중 14/18, 17/18 동일). 효과는 근거 단위(비고·주석·참조를 부모 조회로 붙이는 것)에서 나왔다.
2. **공통 표현·순위 결합 보완(다음 실험에서 고정한 뒤 새 질문으로 평가):**
   - 숫자·단위 분리("1㎥"→"1 ㎥"), 조사 제거, "레미콘↔레디믹스트콘크리트"류 동의어 목록은 질문별 보정이 아니라 **공통 규칙**으로 사전에 고정해야 한다. 이번에는 사전 고정 규칙 4개만 썼다.
   - 의도 하나로 색인을 고르지 말고 목록·규칙·표 결과를 순위로 합치는 방식(예: 순위 합산) 검토. Q07처럼 표와 주석이 서로 다른 색인에 있을 때 필요하다.
   - 짧은 청크 편중(길이 정규화) 완화 검토.
3. **답 없음 판별:** 점수만으로는 불가능하다. 최소한 질문 낱말 중 자료에서 겹친 비율이나 "핵심 낱말이 하나도 자료 제목에 없음" 같은 신호를 설계할지 결정이 필요하다. 이번에는 구현하지 않았다.
4. **API 허용 시 의미 검색 검증:** 같은 20문과 같은 기대 후보 집합, 같은 근거 규칙으로 BM25·벡터·결합을 비교하고, 이번에 본 질문과 분리한 **새 확인 질문**을 따로 만든다. 임베딩 호출 수·비용은 사전에 정한다.
5. **입력 자료 점검:** 기준 표기 누락 183개(휴리스틱)를 데이터 결함 목록으로 확정할지.
