# 작업 범위 분석 검사 기대

다음 기대값을 검사 코드 실행 전에 기록했습니다. 검사는 로컬 모의 응답만 사용하며 외부 모델을 부르지 않습니다.

| 입력/상태 | 기대 |
|---|---|
| 조적벽에 수성페인트 2회 100㎡ | 도장 1개, 조적벽 바탕, 반복 2회와 면적 100㎡. 분석만으로는 계획 없음 |
| 위 입력을 모든 구절별로 확인 | 기존 EstimateSession 형식의 단일 항목 계획 생성. 원문 위치 보존 |
| 확인된 단일 계획 → `new_session` → `find_work` → 공종 선택 → `compute_labor` | 기존 도구가 물량 100㎡를 유지 |
| 도장100㎡와 전기배선20m | 전기배선 구절을 미확정으로 보존, 계산 준비 안 됨 |
| 도장과 소방/통신/환기/철골/알수없는작업 | 인식 못 한 각 구절을 미확정으로 보존 |
| 도장100㎡ 환기설비2대 | 같은 구절의 인식 못 한 작업을 미확정으로 보존 |
| 내부 도장100㎡와 외부 도장20㎡ | 서로 다른 두 작업과 각 수량 보존, 계산 안 함 |
| 콘크리트벽 도장 | 도장 작업과 바탕면만 남기고 콘크리트 공사를 새 작업으로 만들지 않음 |
| 수성페인트 롤러칠 2회 벽면100㎡, 방수20㎡는 제외 | 확인 후 작업 종류·방식·횟수·바탕·면적 유지. 제외한 방수·20㎡가 도장 입력에 섞이지 않음 |
| 도장 또는 방수 | 선택 전에는 작업 미확정. 확인으로 하나를 선택한 뒤 단일 계획만 가능 |
| `2.5m2`, `0㎡`, `-3㎡`, `10000cm` | 표기와 단위를 원문 그대로 보존. 0·음수·기존 도구가 받지 않는 단위는 계획 보류 |
| 작업·물량·제외 문구가 바뀐 뒤 이전 확인증 재사용 | 거부 |
| 누락·중복 선택, 위조 확인증, 수정된 분석 해시 | 거부 |
| 모델 작업·조건·바탕 일부 누락 | 빠진 원문 구절을 미확정으로 남기고 준비 안 됨 |
| 모델이 다음 작업 수량을 붙이거나 두 작업 수량을 바꿈 | 거부 |
| 모델 근거 위치가 틀리거나 같은 구절 위치가 모호함 | 거부 |
| 모델 형식 오류/장애 | 전체 요청을 미확정으로 돌리고 준비 안 됨 |
