| 2-나 대상 확인 | 문서 버전 + 명시된 부문 + 번호 + 제목을 함께 확인. 확정 / 후보 / 여러 후보 / 다른 부문에만 있음 / 대상 없음 구분. 번호 없는 제목 참조는 출발 쪽 절로 좁히되 후보로 남김. 명시된 대상 부문을 따르며 "같은 부문만" 찾는 규칙으로 바꾸지 않음 | `lookup.py` `Catalog.resolve` |
| 2-다 실제 원문·주석 전달 | 확정된 대상의 제목·범위·기준·표·주석과 위치를 항목으로 전달. 표 소속 주석을 제목이 아니라 표 식별자(owner)로 찾도록 고침. 제목 발견 / 자료 확보 / 묶음 전달을 별도 상태로 기록 | `evidence.py` `deliver_target`, `lookup.py` `fetch` |
| 2-라 길이 한도 | 필수 항목을 먼저 담고, 필수가 빠지면 "필수 근거 미완료"와 계산 사용 보류. 선택 문맥만 빠지면 "완료(선택 문맥 일부 생략)" | `evidence.py` `assemble` |
| 3 표현 | "합산·곱셈 금지" → "여러 행에 표시된 같은 시공량을 중복 합산하지 않음" | `evidence.py` `group_rows_text` |

**고친 시제품의 결함:** 1차 시제품은 참조 대상을 ODL 12쪽 출력 안에서만 찾았고, 번호가 같은 다른 부문 절을 구분하지 못했다(실제로는 6-1-3이 세 부문에 있다). 또 표 아래 주석의 `owner`가 표 식별자인데 제목과 비교해 주석을 0건 가져왔다(기능 검사로 0건 → 4건 확인).
