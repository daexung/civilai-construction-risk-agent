# 프로필의 운영자 대시보드 진입 메뉴

작성일: 2026-10-14

## 변경

상담 화면 왼쪽 아래 프로필 메뉴에 운영자 대시보드 링크를 추가했다. 서버의 `/api/admin/access`에서 기존 Supabase 인증과 서버 UUID 허용 목록을 확인한 계정에만 링크를 보여 준다. 이메일이나 브라우저가 선언한 역할로 권한을 판단하지 않는다. 확인 실패·일반 회원·비로그인 상태에는 숨긴다.

권한 확인 API는 해당 사용자의 접근 가능 여부만 반환하고 통계와 본문은 조회하지 않는다. 기존 캐시 금지·검색 제외 미들웨어와 관리자 접근 제한을 그대로 적용한다. 계정 변경 때 기존 요청을 취소하고 계정에 연결한 결과만 표시하므로 로그아웃 후 링크가 남지 않는다. 링크를 직접 입력해도 기존 관리자 API에서 다시 권한을 확인한다.

## 확인

- 프런트 검사 76개 통과. 일반 회원 메뉴 비노출, 서버 확인 후 관리자 링크 노출·경로, 로그아웃 후 제거 및 기존 상담 기능 회귀를 포함한다.
- 관리자 API 검사 11개 통과. 새 확인 API의 비로그인·다른 회원 거부, 허용 계정 성공, 통계 조회 없는 권한 확인을 포함한다.
- 운영 빌드 성공. 기존 의존성 소스맵 경고가 있었으며 빌드는 완료됐다. 배포 후 실제 프로필 메뉴 이동 결과는 PR에 기록한다.
- DB 마이그레이션, 모델 호출, 관리자 허용 계정 변경은 없다.
