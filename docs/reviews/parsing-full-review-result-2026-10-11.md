# 전체 파싱 생성과 원문 점검 결과

작성일: 2026-10-11. 이번 단계는 완료했다. 전체 파싱 입력의 확정 채택은 보류한다.

## 이번 작업의 결론

**982쪽 전체를 실제로 처리했고, 수정 대상의 위치와 종류를 한 목록으로 만들었다. 현재 후보를 그대로 청킹·임베딩에 넣으면 안 된다.** 원문에 있는 표가 표 형태로 빠지고, 일부 머리글과 설명 칸이 잘못 전달되는 문제가 확인됐다.

이번에 맡은 일은 전체 생성과 점검이다. 파싱 규칙은 고치지 않았다. 이 보고의 숫자는 오류 목록과 작업 범위를 뜻하며 전체 정확도가 아니다.

대목표는 근거와 가정을 보여 주는 여러 공종 견적과 실무용 Excel이다. 지금은 그 첫 단계인 **원문을 믿을 수 있게 보관하고 청킹에 넘길 입력을 정하는 단계**다. 임베딩이나 계산 명세를 바꾼 작업이 아니다.

## 검토의 범위와 한계

새 20쪽은 기존 부문·표 유형 조사에서 선정한 작업 표본이다. 전체 정확도를 추정하는 통계 표본은 아니다. 선정 값·이름·기준·관계를 그림과 대조했으며 58개 표의 모든 칸을 독립 정답으로 작성하지 않았다. 과거 개발 쪽은 제외 목록으로 관리했고, 과거의 모든 읽기 이력을 완전히 증명한 것은 아니다.

원문 글자 위치와 숫자 칸을 비교한 자동 점검은 숫자 칸 26,714개와 단위 칸 935개를 살폈다. 숫자 차이 후보 9칸 중 2칸은 444쪽의 `60, 100`을 숫자 하나로 읽은 비교기의 오탐이었다. 나머지 7칸은 555·834쪽의 추출 문자열 불일치다. 이 점검은 글자가 다른 이름·단위에 연결되는 문제, 아예 빠진 표, 원문 글자층 자체의 오류를 전부 잡지 못한다. 통과율을 정확도로 계산하지 않는다.

확대 판독으로 제외한 의심도 남겼다. 683쪽 우레탄폼 분사 시공량은 원문에도 세제곱 단위로 인쇄돼 있어 단위 오류가 아니다. 791쪽 위 표의 마지막 다섯 행에서 176 압력 칸은 원문도 비어 있다. 791쪽 아래 표 누락과는 별개다.

실행·전달 확인은 최종 12항목 모두 맞았다. 초기에는 빈 쪽에 글자가 전혀 없다고 가정해 꼬리글 8쪽 때문에 한 항목이 실패했다. 원문 위치와 내용을 확인해 이유를 기록했으며 초기 결과를 보존했다. 제목 경로 집계도 실제 상태 이름을 반영한 수정본을 별도 보관했다. **이 확인으로 원문 의미 정확성을 승인하지 않는다.**

다음 쪽 주석의 모든 소속, 모든 참조 대상, 모든 식과 단위의 계산 의미, 운영 ID 대응은 이번에 확정하지 않았다. 정상 표지 2,023개도 계산 승인 표가 아니다. 원문 대조에서 표지 없는 결함이 확인돼 이 후보의 확정 채택은 보류한다.

## 다음 작업 제안과 종료 조건

다음 목적은 **확인된 원문 전달 결함을 한 묶음으로 교정해 청킹 개발 입력을 확정하는 것**이다. 새 파서 비교나 소수 쪽의 반복 실험을 추가하지 않는다. 기존 전체 ODL 출력을 재사용한다.

1. **표 누락 보충:** 확인된 24개 자료 표에 기존 PDF 칸 추출 결과를 적용한다. 원문 영역·칸·값과 복구 결과를 대조한다. 다른 표를 바꾸지 않고 보충 결과의 출처를 남긴다.
2. **공통 출력 수정:** 머리글 경계와 목록 본문, 병합 설명 칸의 내보내기를 한 번에 고친다. 627·980·387쪽을 같은 수정 묶음으로 확인하고 전체 영향 목록을 낸다.
3. **개별 교정 자료:** 555·834쪽 칸과 224쪽 수식을 원문 근거가 있는 별도 교정 자료로 보관한다. 원래 자료를 덮어 지우지 않고 문서 해시와 위치로 적용한다. 문서가 바뀌면 자동 재사용하지 않는다.
4. **보류 목록 정리:** 278개는 사유별로 묶어 공통으로 닫을 수 있는 범위를 먼저 확인한다. 이름·코드·행 관계를 확정하지 못한 항목은 원문 묶음과 보류 상태를 유지한다. 278개를 오류 278건으로 보고 모두 수기로 옮겨 적게 하지 않는다.
5. **한 번의 전체 재생성·결정:** 교정 후 알려진 결함 30개와 수식 1곳을 재대조하고, 전체 출력의 누락·중복·보류 전달을 확인한다. 수정에 사용하지 않은 새 확인 표는 교정 전 고정한다. 남은 예외와 제외 기능을 붙여 청킹 개발의 채택 범위를 결정한다.

이 후속 작업에는 **파싱 후처리 코드 수정과 교정 자료 작성이 필요하다.** 현재 보고 단계에서 이미 수정한 것으로 오해하면 안 된다. 직종·규격·보정치가 최종 계산에 어떻게 쓰이는지 승인하는 일은 이후 계산 단계다. 다만 확정되지 않은 연결을 청킹 입력에서 정상처럼 표시해서는 안 된다.

공통 규칙과 교정 적용·재생성에는 계획상 60~120분을 예상한다. 실제 수정 시간을 측정한 보장은 아니다. 278개 전체를 직접 판독하는 시간은 별도이며 지금 확정할 수 없다. 후속 작업은 우선 90분으로 제한해 완료 범위와 남은 예외를 보고하도록 권한다. 시간 안에 끝나지 않은 것을 완료로 선언하거나 자동으로 새 수정 회차를 붙이지 않는다.

후속 단계의 완료 조건은 확인된 결함이 교정되거나 후속 사용에서 명확하게 제외되고, 교정 적용 위치가 재현되며, 미확정 자료가 정상 행으로 전달되지 않는 것이다. 새 원문 대조에서 중요한 오류가 정상으로 전달되면 전체 입력 채택을 계속 보류하고 실패 유형에 따른 범위 축소 판단을 제출한다. 보류 비율만으로 통과시키지 않는다.
