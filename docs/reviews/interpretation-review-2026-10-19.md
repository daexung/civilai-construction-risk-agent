방법: 해당 PDF 쪽을 이미지로 열어 표의 칸 배치(병합 셀 범위)·비고·각주를 직접 읽고 명세 표와 한 칸씩 대응시켰다.
"숫자가 텍스트에 있다"는 검사(`check_promoted_unsupported_calc.py`의 토큰)는 값의 존재만 보며, 아래 확인은 그것과 별개다.

## 유지관리 2-1-5 (절삭 후 콘크리트 덧씌우기) — 보통인부 합산
- 원문(p.931): 보통인부가 `(절삭) 1`, `(청소) 1`, `(포설) 4`의 세 줄로 적힌다. 모두 같은 직종(보통인부), 시공량 열은 줄 전체에 걸친 병합 셀(밀링깊이 100㎜ 2,500 / 150㎜ 1,600).
- 명세는 세 줄을 보통인부 6인으로 합쳤다. 합쳐도 인·일과 노임(같은 직종)은 변하지 않는다. 바뀌는 것은 표시뿐(작업 단계별 구분이 사라짐).
- 판정: 계산 영향 없음(대응 확정). 단계별로 보이려면 줄을 나눠 직종명 `보통인부`로 합산 표기하는 표시 정책만 남는다.
- 같은 쪽의 `④ 절삭 시 1㎥당 팁(날) 0.69개`는 절삭 체적이 필요해 미산정으로 남겼다(입력 없음).

## 유지관리 2-1-6 (아스팔트 절삭 및 덧씌우기) — 롤러 교체
- 표(p.932): 절삭/덧씌우기 포장 열별 수량·시공량(2,900 / 2,000)과 장비 줄별 대수를 칸 단위로 대조했고 명세와 일치한다(덧씌우기: 포장공 4, 보통인부 1, 로더 1, 피니셔·머캐덤·타이어·탠덤·플레이트콤팩터·살수차·스프레이어 각 1).
- 비고 원문: "개질아스팔트 10%, 투배수성 20% 시공량을 감하고, 사용기계에서 타이어롤러 대신 머캐덤롤러(10~12t) 1대를 추가로 계상한다."
- 해석 A(적용): 타이어롤러를 빼고 머캐덤롤러를 1대 추가 → 머캐덤롤러 2대, 타이어롤러 0대. "대신"과 "추가로 계상"이 함께 있어 가장 자연스러운 읽기다.
- 해석 B: 표의 머캐덤롤러 1대는 그대로이고 타이어롤러만 머캐덤으로 바뀐다 → 머캐덤 1대(+"추가" 문구 무의미). "추가로"와 맞지 않는다.
- 계산 영향: 노무량·작업일수는 같다. 장비 대·일만 달라진다(A: 머캐덤 2·타이어 0, B: 머캐덤 1·타이어 0 또는 1). 장비 단가가 없는 항목이라 금액은 미산정이며 영향 없음.
- 판정: A로 계산하되 **원문이 숫자로 확정하지 않은 읽기**이므로 해석 확인 필요로 기록. 정책 결정이 필요한 것은 이 한 가지: 개질·투배수성 덧씌우기의 머캐덤롤러 총 대수(2대 vs 1대).
