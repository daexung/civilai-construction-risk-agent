# 186쪽 6-1-3 표 산출 기준 보존 확인 (단일 사례)

기준 코드: `baf186f`의 `pipeline/parse.py:78-104` (`read_text_blocks`). 입력은 `experiments/table_census/results/tables.json`의 `p186-t0` 좌표(68.5·227.3·543.5·258.2)와 PDF 186쪽의 기존 글자층뿐이다. 새 표 추출·파싱 실행은 하지 않았고, 저장소 파일은 이 문서 외에 바꾸지 않았다.

## 요약

- **기존 방식:** `(100㎡당)`이 **남지 않는다.**
- **시제품:** `(100㎡당)`이 **남는다.** 표 안 글자는 **중복해서 남지 않는다.**
- **이번에 확인하지 않은 것:** 다른 표에서의 일반성, 표와 기준의 최종 연결, 운영 적용.

## 원인 (코드 확인)

`pipeline/parse.py:95-100`은 `page.get_text("blocks")`의 블록 하나의 중심 좌표만 보고, 중심이 표 안이면 블록 전체를 버린다. 186쪽에서 PDF가 `(100㎡당)`과 표 안 글자(`구 분 단 위 수 량 미 장 공 인 0.34`)를 **한 블록**으로 묶는다.

| 대상 | bbox (x0·y0·x1·y1) |
|---|---|
| 합쳐진 블록 | 73.1 · 213.4 · 544.3 · 256.6 |
| 블록 중심 y | (213.4+256.6)/2 = 235.0 → 표(227.3~258.2) 안 → **블록 통째로 버림** |
| `(100㎡당)` 줄 | 501.1 · 213.4 · 544.3 · 224.4 (표 위쪽선 227.3보다 2.9pt 위) |

## 시제품 (메모리에서만 검사)

판정 단위를 블록에서 줄로 바꾼다. `get_text("dict")`의 줄마다 중심이 표 안(기존과 같은 ±2pt 허용)이면 버리고, 아니면 남긴다. 머리글·절 제목 필터와 표 좌표는 기존과 같다.

## 남은 글자 나란히 보기 (186쪽, 제목 `6-1-3` 아래 ~ `[주]` 줄)

| | 기존 방식 | 시제품 |
|---|---|---|
| `(100㎡당)` | **없음** | **있음** (y 213.4) |
| `구 분` `단 위` `수 량` | 없음 | 없음 |
| `미` `장` `공` `인` `0.34` | 없음 | 없음 |
| `[주] 본 품은 콘크리트 타설 후 쇠흙손을 이용하여 마감하는 기준이다.` | 있음 | 있음 |

표 안 글자 8줄(`구 분`, `단 위`, `수 량`, `미`, `장`, `공`, `인`, `0.34`)은 두 방식 모두 바깥 글자로 남지 않는다. 시제품에서 남은 줄 중 표 안 줄과 같은 글자이거나 표 안 줄과 겹치는 줄은 없다.

## 쪽 전체 차이

같은 쪽의 다른 표 `p186-t1`(6-1-4 인력편성)도 좌표에 넣어 비교했다. 쪽 전체 바깥 글자는 기존 13블록, 시제품 14블록이고, **차이는 `(100㎡당)` 한 줄뿐**이다. 기존에만 있는 글자는 없다.

## 한계

- 한 쪽의 표 한 개 결과다. 기준이 표 바깥 위에 있지만 표 안과 같은 줄·같은 블록에 걸리는 다른 배치(예: 표 위쪽선과 겹치는 줄)는 확인하지 않았다.
- 이 판정은 줄 중심만 본다. 표 경계에 걸친 줄은 `(100㎡당)`처럼 여유(2.9pt)가 있을 때만 안전하다.
- `(100㎡당)`을 6-1-3 표의 `0.34인`에 연결하는 일은 하지 않았다. 지금은 "표 바깥 글자로 남는다"까지만 확인했다.
