# 대시보드 팝업 차단 수정

작성일: 2026-10-14

## 문제와 변경

운영 로그인 공개 설정 누락을 복구한 뒤에도 브라우저 팝업 차단으로 대시보드에 로그인하지 못했다. 대시보드는 이제 같은 탭에서 Google 계정을 선택하고 인증한다. 기존에 허용된 `/auth/callback`으로 돌아와 세션 확인 후 고정된 `/admin`으로 이동한다. 다른 사이트 주소를 복귀 경로로 사용하지 않는다.

기존 상담 로그인과 회원탈퇴 재인증은 기존 팝업 경로를 유지한다. 관리자 권한 확인과 서버 허용 목록은 바꾸지 않았다. 로그인 시작 중에는 버튼을 잠그고, 시작 실패 시 다시 시도할 수 있게 한다.

## 확인

- 프런트 검사 75개 통과. 팝업 차단 중 대시보드 인증 시작, 인증 시작 실패 후 재시도, 외부 복귀 주소 거부, 실제 콜백 컴포넌트의 대시보드 복귀를 포함한다.
- 기존 가짜 타이머 정리 경고가 있었고 검사 실패는 없었다.
- 운영 빌드와 홈페이지 사전 렌더링 성공. 기존 의존성의 소스맵 경고가 있었고 빌드는 완료됐다. 실제 브라우저 확인 결과는 PR의 배포 기록에 남긴다. 검사에서 실제 Google 사용자 인증을 대신하지 않는다.
- 새 모델 호출과 DB 마이그레이션은 없다. 인증 토큰이나 사용자 계정 식별자는 문서에 넣지 않는다.
