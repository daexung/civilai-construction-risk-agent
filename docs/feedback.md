# 피드백 접수

채팅 왼쪽 패널의 ‘피드백 남기기’에서 회원과 비회원 모두 의견을 제출할 수 있습니다. 오류 제보·개선 제안·기타 의견을 구분하며, 내용은 공백 제거 후 5~2,000자입니다. 대화, 이메일, 브라우저 정보는 자동 첨부하지 않습니다.

운영자는 Supabase 프로젝트의 **Table Editor → public → feedback**에서 접수 내용을 확인합니다. `created_at` 내림차순으로 정렬하고, 확인한 의견은 `status`를 `reviewed`, 처리 완료한 의견은 `resolved`로 변경할 수 있습니다. 메일 자동 알림과 개별 답변은 현재 제공하지 않습니다. 서비스 이용자에게는 이 테이블의 읽기·쓰기 권한이 없습니다.

서버에서 검증한 회원 식별자 또는 비회원 IP의 HMAC을 기준으로 1분 간격·하루 5건을 제한합니다. 전체 접수 한도는 하루 100건이며 한국 시간 자정에 초기화됩니다. 견적 일일 사용량과 별도입니다. 동일 요청 ID와 내용의 재시도는 한 번만 저장하며, PostgreSQL 트랜잭션으로 동시 요청도 제한합니다. 프록시 배포 시 비회원 IP 전달 방식은 채팅 제한과 함께 검증해야 합니다.

내용은 90일보다 오래되면 이후 접수 과정에서 삭제하며, 접수 제한 집계는 7일보다 오래된 날짜를 정리합니다. 접수가 없는 동안에는 정리가 실행되지 않습니다. 공개 운영에서는 예정된 보관 기간에 맞춰 별도 정기 삭제 작업을 설정해야 합니다.

스키마: `supabase/migrations/20261006000400_feedback.sql`. API: `POST /api/feedback`. 외부 메일 서비스나 AI 모델을 호출하지 않습니다.
