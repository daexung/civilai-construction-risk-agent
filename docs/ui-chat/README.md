# 품셈이 채팅 화면

2026-10-06: https://univai.co.kr/aichat 의 실제 채팅 화면을 참고해 `/chat` 화면을 구현했습니다.

- 260px 밝은 사이드바, 상단 제목과 새 대화 버튼
- 중앙 안내 문구, 둥근 입력창, 짧은 예시 질문 버튼
- 기존 조건 선택, 계산 결과 탭, 엑셀 내보내기와 원문 패널 유지
- 900px 미만에서 사이드바를 접히는 메뉴로 전환
- 한글 조합 중 Enter 전송 방지, 예시 메뉴 Escape 닫기, 새 대화 시 입력 초안 초기화

검증: 프로덕션 빌드, 프런트엔드 테스트 5개 통과. 실제 API로 콘크리트 타설 질문 → 조건 선택 → 견적 계산 → 산출근거 → PDF 원문 보기 확인. 320px 및 390px 모바일 화면에서 가로 넘침 없음.

`chat-desktop.jpg`, `chat-mobile.jpg`는 로컬 브라우저에서 촬영한 구현 화면입니다.

## 대화 목록

고정된 ‘품셈이 (AI 채팅)’ 메뉴를 제거하고 빈 대화에서 ‘새 대화’를 강조합니다. 첫 질문을 제목으로 대화 목록을 만들고, 선택한 대화의 질문·응답 및 서버 thread ID를 복원합니다. 새 대화는 질문을 보내기 전까지 목록에 추가하지 않습니다. 이 브라우저의 localStorage에 대화 목록과 선택 상태를 저장합니다. 응답 중에는 대화 전환을 막습니다.

대화 생성·전환·원래 thread로 후속 요청·새로고침 복원 및 응답 중 전환 방지 테스트를 포함한 7개 테스트와 프로덕션 빌드가 통과했습니다. 실제 API로 두 대화를 생성하고 목록에서 전환한 뒤 새로고침해 복원을 확인했습니다. `chat-history.jpg`는 새 대화 선택 상태와 기존 대화 목록입니다.

## 브랜드 색상

랜딩과 채팅은 `index.css`의 `--brand-primary`, `--brand-strong`을 공유합니다. 채팅 브랜드명은 짙은 초록색, 사이드바는 옅은 초록빛, 선택 메뉴는 연초록 배경입니다. 입력창 포커스와 활성 전송 버튼, 견적 금액과 선택된 결과 탭, 원문 보기 및 도급액 행에도 브랜드 색상을 적용했습니다. 흰색 본문은 유지합니다. 프로덕션 빌드와 브라우저에서 실제 색상 적용을 확인했습니다. `chat-brand-green.jpg`는 선택 메뉴와 입력 중 전송 버튼을 보여줍니다.
