# 품셈이 이용 통계

PostHog 미국 클라우드 프로젝트를 사용한다. 프론트 빌드 환경에 아래 값을 설정한다.

```env
REACT_APP_POSTHOG_KEY=프로젝트_토큰
REACT_APP_POSTHOG_HOST=https://us.i.posthog.com
```

프로젝트 토큰은 클라이언트 수집용 공개 키이며 Personal API key를 프론트에 넣지 않는다.
현재 로컬 주소는 수집에서 제외한다. 설치 확인이 필요할 때만 `REACT_APP_POSTHOG_TRACK_LOCAL=true`로 빌드한다.
정적 미리보기 HTML에는 앱 JavaScript가 없으므로 이벤트가 발생하지 않는다.

## 이벤트

| 이벤트 | 발생 시점 | 추가 항목 |
|---|---|---|
| `$pageview` | 랜딩·챗·약관·개인정보 페이지 진입 | 정해진 페이지 경로 |
| `question_submitted` | 질문 또는 조건 답변을 전송할 때 | 회원 여부 |
| `estimate_downloaded` | 엑셀 파일을 받아 다운로드 동작을 실행한 뒤 | 회원 여부 |
| `feedback_submitted` | 서버가 의견 접수를 완료한 뒤 | 의견 유형·회원 여부 |
| `answer_rated` | 서버가 답변 평가를 저장한 뒤 | 평가·사유 코드·회원 여부 |

질문 전송은 견적 성공 건수나 실제 AI 호출 횟수가 아니다. 조건 재계산의 버튼 동작과 AI 호출·토큰·비용은 별도 서버 지표로 집계해야 한다.
전체 회원 수는 Supabase로 집계한다. 브라우저 식별자를 계정에 연결하지 않으므로 방문자 수를 회원 수나 사람 수로 간주하지 않는다.
다른 기기·브라우저·저장소 삭제·수집 거부에 따라 방문자 집계가 달라질 수 있다.

## 개인정보와 선택

자동 클릭 수집, 녹화, 히트맵, 설문과 프로필 식별을 끈다. 전송 직전 이벤트·속성을 허용 목록으로 필터링한다.
본문, 대화/계정 식별자, 이름, 이메일, URL 질의·해시, 리퍼러·페이지 제목은 보내지 않는다.
무작위 브라우저 식별자를 로컬 저장소에서 유지하며 SDK의 위치 추정과 이벤트 IP 저장은 비활성화한다.
통신 서버가 네트워크 접속 IP를 받는 것까지 차단한다는 의미는 아니다.
설정 → 일반에서 통계를 끌 수 있고 Do Not Track을 존중한다. 수집 실패·차단은 서비스 기능을 막지 않는다.
개인정보처리방침에 수집 항목·미국 이전·무료 플랜의 현재 1년 보관 기간을 기재했다.
공개 전에 국외 이전의 적법한 근거, 제공자 상세 정보·연락처와 이용자 안내/선택 절차를 확정해야 한다.

## 운영

PostHog Web Analytics에서 방문 추이를 보고 Insights에서 이벤트별 이용 추이를 추가한다.
설치 확인 이벤트는 `environment=installation_test`로 별도 표시한다. 실제 대시보드 집계에서 제외한다.
SDK는 비동기 청크로 불러오며 대화 렌더링·서버 응답을 기다리게 하지 않는다.
