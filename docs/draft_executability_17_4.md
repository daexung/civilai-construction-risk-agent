# 17-4 초안 계산 재측정

17-3 기준 커밋 `c86e453`의 실행 가능 목록과 비교했다. 계산형 초안 718건 중 형식·인용 검사 통과 건을 계산기로 실행하며, 기본 조합은 계산되어야 한다. 다른 조합은 계산 또는 보류를 허용하고 최대 64개 입력 조합을 확인한다. 재량 질문은 기본값이 없어야 하며 예·아니오 응답을 각각 검사한다. 기본 조합의 질문 상태는 실행 가능으로 세지 않는다. 전체 초안은 1,058건이며 서비스 범위는 공통 6장 그대로다.

| 분류 | 17-3 | 17-4 | 증가 |
|---|---:|---:|---:|
| daily_crew | 138/226 | 172/226 | 34 |
| per_unit | 144/492 | 210/492 | 66 |
| 전체 | 282/718 | 382/718 | 100 |
| 공통 6장 | 15/31 | 23/31 | 8 |

기존 실행 가능 ID 중 제외된 건은 없다. 이 결과는 제한된 조합에서의 계산기 실행 가능성으로, 모든 입력 조합의 정확성이나 서비스 공개 승인을 뜻하지 않는다.

## 할증 규칙 분류

조건 조합 수가 아닌 규칙 255건의 정적 분류다. enum 기본값과 규칙 조건으로 대표 입력을 구성해 원문 근거를 찾는다. 17-3은 자동 2건, 보류 253건, 메모 0건이었다.

| 분류 | 건수 |
|---|---:|
| 자동 적용 | 63 |
| 사용자 확인 | 11 |
| 보류: 비율 범위 | 6 |
| 보류: 누적·공식 | 1 |
| 보류: 기타·근거 미확인 | 154 |
| 숫자 없는 설명 메모 | 20 |
| 합계 | 255 |

근거를 찾지 못하면 기타 보류로 먼저 분류하므로 누적·공식 1건이 초안 전체의 누적 규칙 수를 의미하지 않는다. 위치 설명의 페이지·절 번호는 할증 수치로 취급하지 않는다.

## 오류 원인과 남은 실패

이전 AttributeError의 원인은 `quantity_model.params.equipment`가 dict뿐 아니라 list로도 저장된 데 있었다. 장비 목록을 순회하도록 수정했다. `coefficients` 누락은 빈 목록으로 처리한다. 음수 퍼센트와 괄호 설명이 붙은 장비 대수를 읽으며 단위 None은 1단위와 경고로 처리한다. D35 이상 입력의 기본값은 35로 선택하고, 할증 조건의 수치 경계도 추가 검사한다.

## 기존 검사 변경

- `check_api.py`: 허용된 E2 기대 상태를 BLOCKED에서 재량 적용 질문(MISSING_INFO)으로 바꾸고 답변 후 계산을 추가했다.
- `check_adjustments.py`: E2 비계 및 같은 재량 문구의 보류 기대를 질문으로 전환했다. 원문 조회 mock을 `_source`에서 `_evidence`로 맞췄다. G1·G2, 요율 표 인용, 19층 이상·직경 증가 누적 보류 및 페이지 번호를 포함한 메모 경계 검사를 추가했다.
- `check_per_unit.py`: 기본품·하한·음수 퍼센트·장비 대수·단위 없음·장비 목록 검사를 추가했다. 기존 금액 기대값은 바꾸지 않았다.
- `check_draft_executability.py`: 재량 질문의 예·아니오와 숫자 경계를 검사하고 분류를 재집계한다.

이번 마무리에서 기존 기대값을 추가 변경하지 않았다. `.env`를 읽거나 외부 API를 호출하지 않았다.
