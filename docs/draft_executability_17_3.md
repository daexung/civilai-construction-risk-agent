## 공통 6장 변화

새로 계산 가능: 6-1-5 에폭시 접착제, 6-1-6 콘크리트 치핑, 6-2-6 GFRP 보강근, 6-3-5 합성수지 원형 맨홀 거푸집, 6-3-6 슬립폼, 6-3-8 갱폼, 6-5-2 솔 플레이트 용접, 6-6-4 철도교 신축이음, 6-6-8 교량 배수시설.

실행 가능 목록에서 제외: 초안 6-1-4 펌프차 타설은 `1대(80㎥/hr 이상)` 셀 값 해석 실패, 초안 6-3-10 신축이음은 동적 표 ID 미해결. 6-1-4는 기존 검토 완료 명세가 우선하므로 서비스 골든 계산에 변화가 없다.

기존 검사 A2/G2는 재측정 중 합판거푸집 초안이 일시 제외되어 실패했으나, 명시적 행·열과 장비 없는 작업조를 읽도록 수정하여 다시 통과했다. R1, M1, S1, 펌프 C1, 사급 견적의 기대 금액은 변경하지 않았다.
