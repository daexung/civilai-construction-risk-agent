4h는 정답 근거 보존을 개선했지만 G02의 불필요 보류와 N19 자료 없음 미달이 남았다. 이번에는 표현 예외를 추가하거나 모델을 다시 부르지 않는다. 약한 낱말 분석과 추가 대조 경고의 보류 권한을 분리해 어느 규칙이 정상·자료 없음 질문에 영향을 주는지 비교하고 채택 가능한 정책을 추천한다.

## 1. 비교 방식

다음 네 가지를 같은 저장 응답과 원문에서 비교한다.

| 방식 | 약한 낱말 부재만으로 보류·전체 강등 | 대조 경고만으로 보류·해당 근거 강등 |
|---|---|---|
| 가: 4h 기준선 | 유지 | 유지 |
| 나 | 해제 | 유지 |
| 다 | 유지 | 해제 |
| 라 | 해제 | 해제 |

해제는 정보 삭제가 아니라 자동 상태·근거 역할 변경 권한만 제거한다. 질문 원문·분석·경고·사유와 실제 대조 결과는 진단 정보로 보존한다. 대조는 어떤 방식에서도 근거를 제외하거나 `supported`로 승격하지 않는다.

소속 미확정·수식 미확정·참조 미해결·제목 소유 경쟁·필수 근거 누락·예산 제외·목록 불완전·부정 조건 등 다른 보류 규칙은 네 방식에서 동일하게 유지한다. 유효하지 않은 ID·위치·버전은 그대로 거부한다. 질문 ID·특정 단어·정답 근거 ID로 분기하지 않는다.

단순히 결과 JSON에서 이유를 지우고 상태를 `supported`로 바꾸는 집계는 금지한다. 격리된 비교용 코드 경로에서 최종 상태와 근거 역할·정상 답변/검토용/진단 분류를 다시 계산해야 한다. 응답에 `missing`이나 다른 보류 사유가 있으면 계속 반영한다. 바꾸는 두 권한 외의 실행 동작이 같음을 확인한다.

## 2. 저장 응답과 불변 범위

현재 `src/select_verified.py`와 운영 코드는 바꾸지 않는다. 필요한 비교용 복사본 또는 어댑터는 `experiments/retrieval-v1/pilots/step04i/` 아래에 둔다. 기존 4h 캐시·원장·결과는 덮어쓰지 않는다.

원문 릴리스·청킹 묶음·문서 벡터·검증 DB 자료·질문 기대값을 유지한다. 같은 입력 해시의 저장 응답만 사용한다. 선택 응답·대조 응답·목록 응답을 모두 원래 입력과 연결한다. 재생에 필요한 응답이 없으면 미실행으로 기록하고 외부 호출하지 않는다.

새 모델·임베딩·외부 API 호출은 **0회**, 새 유료 비용도 **0**이다. 재생 도구에서 캐시 미스나 외부 호출 시도가 있으면 즉시 막는다. 로컬 DB는 읽기 전용이며 필요하면 기존 로컬 환경만 시작한다. 다른 작업의 프로세스와 변경 파일을 건드리지 않는다.

## 3. 실행 순서

1. 가 방식으로 4h 최종 결과를 재현해 기준선을 확인한다.
2. G02·N19와 G03·G09·G10, 기존 동의어·구어체·자료 없음·소속/수식 미확정 사례를 먼저 비교한다. 기대값은 기존 원문 기준을 유지한다.
3. 기존 60문과 4g 20문, 저장 응답이 있는 4h 개발 대조 사례를 네 방식으로 한 번씩 재생한다. 4g는 이미 수정에 사용한 개발 자료라는 표시를 유지한다.
4. 결과를 보고 새로운 임계값·예외·프롬프트 수정으로 추가 비교안을 만들지 않는다. 보고하고 종료한다.

## 4. 우선 판단과 지표

G02가 불필요 보류에서 풀리는 것만으로 정책이 좋다고 판단하지 않는다. N19나 다른 자료 없음 질문에서 관련 없는 표가 정상 근거로 올라가는지도 확인한다. 근거 ID가 유효하다는 것은 질문에 맞다는 증명이 아니다.

방식별로 다음을 같은 기준으로 집계한다.

- 원문 기준 필수 근거 전달과 정상/검토용/진단의 역할.
- 정상 질문의 불필요 보류·잘못된 거부.
- 자료 없음 질문에서 관련 없는 정상·검토용 문맥과 잘못된 `supported`.
- 다른 대상 표의 정상 전달·금지 문맥 혼입·미확정 승격.
- 기존 수식·소속·참조·목록·부정 보류 유지.
- G02·N19 등 바뀐 사례의 모든 상태 사유와 변화 원인.

자료 없음 분모에서 N19를 빼지 않는다. `needs_confirmation`을 `not_found` 성공으로 세지 않는다. 진단 후보를 답변 문맥이나 필수 포함 집계에 넣지 않는다. 네 방식의 비교 결과는 개발·회귀이며 독립 정확도가 아니다.

## 5. 결정과 종료

잘못된 정상 근거 전달 없이 불필요 보류를 줄이는 방식이 있으면 해당 정책을 다음 적용 후보로 추천한다. 이번에 기본 정책을 자동 전환하지 않는다.

어떤 방식도 두 문제를 함께 해결하지 못하면 그대로 결론 낸다. 그 경우 G02 단어 예외나 N19 차단을 추가하지 않는다. 현재 경로의 대상 동일성 판단이 부족한 범위를 명시하고, 원문 검토 도구로만 시험할 준비와 자동 답변에 부족한 부분을 구분한다.
