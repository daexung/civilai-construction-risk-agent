## 실행 순서

1. **기준선 보관**
   - 최신 수정본과 출력의 버전을 확인한다.
   - `experiments/parsing-row-mapping-6-2026-10-11`을 이번 작업 폴더로 만든다. 이미 있으면 내용을 확인하고 기존 결과를 덮어쓰지 않는다.
   - 필요한 코드와 기존 교정 자료를 복사하거나 읽기 전용으로 참조한다. 복사한 실행 파일의 입력 경로와 출력 경로를 확인한다. 새 출력은 이번 폴더에만 쓴다.
   - 대상 6개 표의 수정 전 레코드·원문 연결·보류 사유를 저장한다. 비교 기준은 직전 수정본 `parsing-corrections-2026-10-11`의 전체 출력이다.

2. **원문으로 기대 결과 결정**
   - 5쪽의 대상 6개 표를 그림으로 직접 대조한다. 원문 선, 병합, 글자 위치, 문장 뜻을 함께 확인한다.
   - 각 문제 칸을 `한 행 안의 줄바꿈`, `별도 행`, `여러 행에 공통으로 적용되는 칸`, `근거 부족`으로 구분한다.
   - 수정 결과를 보기 전에 각 표의 기대 행 구성을 기록한다. 대응을 확인한 원문 글자·칸 위치와 근거를 함께 기록한다.
   - 여러 칸의 줄 수가 같다는 이유만으로 순서대로 연결하지 않는다. 위치가 같다는 사실만으로 적용 의미가 확정됐다고 하지 않는다.

3. **확정한 대응을 실제로 적용**
   - 기존 `source_corrections.py`의 문서 버전 확인과 교정 기록 방식을 먼저 검토한다.
   - 이번 범위에서는 확인한 표의 행 연결을 교정 자료로 기록하고 이를 읽는 최소한의 경로를 추가하는 방식을 우선한다. 정확한 저장 형식과 적용 위치는 실제 코드를 읽고 정한다.
   - 원래 칸과 글자를 보존한다. 분리한 행은 원래 칸 식별자와 사용한 글자 범위 또는 위치로 돌아갈 수 있어야 한다. 공통 칸은 여러 행이 같은 원문 칸을 가리키도록 한다.
   - 교정 전 원문 버전과 표·칸·내용이 맞을 때만 적용한다. 원문이 바뀌거나 대응이 어긋나면 조용히 잘못 적용하지 말고 오류나 보류를 낸다.
   - 원문 대조로 확정한 대응만 해당 보류 사유를 해제한다. 다른 보류 사유가 있으면 유지한다. 표시만 지우거나 판정 기준을 느슨하게 하지 않는다.
   - 범용 파서 규칙을 넓혀 다른 표까지 바꾸는 작업은 이번 범위에 넣지 않는다. 근거가 부족하면 추측하지 않고 해당 표를 보류로 남긴다.

4. **결과 생성과 비교**
   - 같은 ODL 원시 출력과 기존 교정 자료를 재사용한다. ODL 전체 재추출과 새 서비스 도입은 필요하지 않다.
   - 먼저 대상 표 결과를 확인한 뒤, 수정 경로가 적용되는 전체 982쪽 결과를 이번 폴더에 한 번 생성한다.
   - 대상 6개 밖의 표·기준·주석 내용과 보류 상태가 직전 수정본과 같은지 비교한다. 생성 식별자 같은 버전 정보는 내용 비교와 구분한다.
   - 기존 확인 코드를 재사용하고, 이번 행 연결에 필요한 원문 대조와 적용 거부 확인을 추가한다. 통과를 위해 기대 결과를 실제 출력에 맞춰 바꾸지 않는다.
   - 기존 검사 일부는 최초 전체 점검 출력과 비교한다. 그것만으로 이번 변경의 영향이 없다고 결론 내리지 말고, 반드시 직전 수정본과의 비교도 추가한다.

## 완료 기준

- 대상 6개 표마다 원문 그림, 기대 행 구성, 수정 전후 결과, 판정 근거가 있다.
- 행 분리나 공통 값 전달로 글자와 숫자가 빠지거나 잘못 중복되지 않는다. 원문 연결이 유지된다.
- 실제 확인으로 해결한 문제만 보류를 해제하고, 해결하지 못한 표는 구체적인 이유와 함께 남긴다.
- 대상 밖의 내용과 보류 상태가 직전 수정본 그대로다. 차이가 생기면 원인을 해결한 뒤 최종 결과를 다시 만든다.
- 기존 교정 표 24개와 칸 8개, 수식, 머리글·목록·설명 수정이 유지된다.
- 다른 문서 버전 또는 예상 내용 불일치에서는 행 교정을 적용하지 않는 확인이 있다.
- 최종 출력이 최종 코드·교정 자료의 버전과 맞는다.

6개 모두 해결했다고 보고하려고 무리하게 보류를 지우지 않는다. 근거 부족이 남으면 해결한 수와 남은 수를 나눠 보고한다. 설명 표의 보류 해제가 견적 계산의 승인이라는 뜻은 아니다.
