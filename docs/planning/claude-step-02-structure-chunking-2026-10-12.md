## 생성 규칙

1. `work`: 실제 본문 공종·절의 제목과 원문에 있는 적용 범위를 담는다. 목차만 보고 설명이나 범위를 만들어내지 않는다. 장·상위 묶음은 부모 조회용으로 보존한다.
2. `rule`: 번호 항목·문단·완결된 설명을 기준으로 나눈다. 일반 설명도 포함한다. 조건과 예외가 떨어지면 같은 부모로 연결한다. 소속 미확정 글은 미확정 상태로 보존하고 가까운 표의 확정 주석으로 붙이지 않는다.
3. `table`: 작은 표는 전체, 큰 표는 완결된 공법·조건·행 묶음으로 나눈다. 필요한 제목·머리글·행 이름·단위·기준을 포함한다. 공동 값은 원문 칸 식별자와 적용 범위를 유지한다. 반복된 값은 별도 수량이라고 표현하지 않는다.
4. 설명은 약 800토큰, 표는 약 1,600토큰을 시작 목표로 삼는다. 길이보다 의미 경계를 우선한다. 겹침은 기본 0이다. 토큰 계산은 이번 단계에서 외부 API 없이 수행하며 계산 방법과 추정 여부를 기록한다. 기존 계획의 6,000토큰 안전 상한도 추정이라면 그렇게 표시한다. 실제 모델 한도 확인은 임베딩 단계에서 한다. 조용히 자르지 말고 큰 조각은 구조 경계로 나누거나 과대 상태로 보존한다.
5. 쪽 경계만으로 나누지 않는다. 이어지는 표는 확정 관계만 묶고 후보는 후보로 남긴다. 수식 미확정과 표 보류 상태를 유지한다.
6. 목차·표지·반복 머리글은 검색 조각에서 제외하되 원문과 제외 사유를 보존한다. 글이 같아도 위치가 다르면 서로 다른 원문이다.

## 연결을 사용하는 방법

청크마다 원문 노드·레코드·칸, 절, 부모 표나 설명, 관련 기준·주석과 참조 출발점을 추적할 수 있게 한다. 하나의 연결 컬럼에 모든 대상을 문자열로 몰아넣지 않는다. 필요한 대응 테이블을 사용한다.

특히 길어깨 교정 장부의 `superseded_relations` 15건은 청킹 소속과 부모·주석 연결에서 **실제로 제외**한다. 기록만 읽고 기존 관계를 다시 따라가면 실패다. 길어깨 표 세 개와 설명이 인력 작업 절이나 앞 표의 주석 표로 돌아가지 않게 한다. 보완한 `(일당)`도 해당 표 조각에 전달한다.

기존 참조 232개와 추가 후보 9개의 출발점을 청크에서 찾을 수 있게 한다. 대상 절 ID, 원문 문장, 조건, 확인 상태를 조회 가능하게 유지한다. 참조 내용 전체를 모든 청크에 반복 삽입하지 않는다. 조회할 연결을 저장한다. 부분 확인·여러 후보·대상 없음 22개를 확정으로 바꾸지 않는다. 대상 확인과 공사에 적용 가능함을 구별한다.

이 단계에서는 고정 사례로 ‘청크 → 원문과 부모 → 연결된 절’의 조회가 가능한지 확인한다. 질문별 조건 판단, 최대 2단계 탐색과 문맥 예산을 갖춘 전체 근거 조회기는 다음 단계에서 구현한다. 미확정 설명을 근거 조회에서 확정으로 만드는 규칙은 추가하지 않는다.

## 저장과 재현

로컬 `rag_knowledge`에 `chunks`, `chunk_sources`와 필요한 연결 테이블을 추가한다. 이미 있는 원문·연결 테이블은 재사용한다. 청킹 결과에는 원문 릴리스 ID와 청킹 코드·설정·입력 해시로 결정하는 별도 버전 식별자를 둔다. 기존 원문 릴리스 결과 파일을 덮어쓰지 않는다.

청크 ID는 원문 식별자·범위·규칙 버전으로 결정한다. 같은 입력과 설정에서 같은 ID·내용·연결이 나와야 한다. 적재는 트랜잭션으로 하고, 실패하면 이전 정상 자료가 유지되게 한다. 임시 생성 결과는 서비스가 읽지 않게 한다.

DB와 같은 내용의 `chunks.jsonl`, 입력 사용처 장부, 크기·보류·제외 집계, 실행 해시를 출력한다. 원문 인용에 반복한 머리글과 검색용 문맥은 역할을 구분한다. 출력물의 해시 목록에 청크 파일도 포함한다. 기존 코드의 120자 미리보기 결과를 원문 전체로 사용하지 않는다.

## 검증과 종료 기준

구현 결과를 보기 전에 고정 사례의 기대 내용을 기록한다. 기존 확인 코드를 재사용하되 이번 청킹에 필요한 검사를 추가한다.

- 입력 23,484행 전체에 사용처나 검색 제외 이유가 있다. 표 2,328개 전체에 청크 또는 부모 조회 경로와 상태가 있다. 이 집계가 모든 표를 정확히 해석했다는 의미는 아니다.
- 길어깨 364~366쪽: 제목·기준·표·설명·참조 소속이 올바르며 앞 인력 표에 붙지 않는다.
- 185쪽 공동 값과 기준·주석: 원문 연결과 적용 범위를 유지하고 반복을 독립 값으로 만들지 않는다.
- 555쪽 13행과 보류, 758쪽 서로 다른 두 값, 교정된 501쪽과 502쪽 수식: 값·행 대응·기존 상태를 보존한다.
- 번호가 여러 부문에 있는 참조, 하위 항목 참조, 부분 연결과 모호한 참조를 구별한다. 추가 후보 9개도 추적할 수 있다.
- 긴 표·긴 설명·부모 조회·검색 제외 사례를 확인한다. 기준·필수 조건을 누락한 채 짧아졌다고 통과시키지 않는다.
- 원문 저장과 참조 상태는 수정 전과 같다. 반복 생성 결과가 같고, 적재 실패 시 정상 자료가 보존된다. 전체 크기 분포·과대 조각·소속 미확정·보류·실행 시간을 실제 수치로 보고한다.
