# 사용 가이드 후속 작업 계획

사용자 요청: 세 단계 계획 중 1단계부터 실행. 원본 참고 기획안은 `GUIDE-PAGE-PLAN-2026-11-19.md`이며 별도로 유지한다.

## 1단계 — 제품 안내 정합성

상태: 완료. 프론트 안내·선택 표시만 수정하며 서버 차감 정책과 에이전트 로직은 유지했다.

- 작업 범위·소속·이어가기·대상 선택의 확정 요청은 차감된다고 사전에 안내한다.
- 현재 ref의 일반 조건 답변은 대화당 30회까지 무료이며, 이후 차감된다. 새 견적 시작·직접 질문·조건 재계산은 차감된다는 예외도 안내한다.
- 카드 선택 자체와 확정 전송을 구분한다. 기존 무료·차감 정책과 에이전트 처리는 변경하지 않는다.
- 작업 범위의 네 가지 선택지는 설명과 쉬운 표시명을 제공한다. 서버로 보내는 원래 선택값·ref는 유지한다.
- 선택 상태는 진한 배경·체크 아이콘·aria-pressed로 표시한다.
- 확정 버튼은 작업 선택/조건 전송을 구분해 최종 금액이 바로 나올 것처럼 안내하지 않는다.
- 로그인 혜택은 하루 20회·계정에 대화 저장·이어서 보기로 정리한다. 계산 완료 견적의 Excel은 비회원도 임시 대화 만료 전 내려받을 수 있음을 별도 설명한다.

검증: 프론트 회귀 테스트·빌드, 모의 LLM/사용량/DB를 사용하는 기존 오프라인 API 검사, 로컬 화면 확인. 실제 모델 호출·사용자 이용 횟수 소모는 하지 않는다.

### 1단계 검증 결과

- 프론트 테스트 13개 스위트 / 113개 테스트 통과.
- 프로덕션 빌드 통과(의존 패키지 소스맵 누락 경고).
- `evals/check_dialogue.py`의 `check_free_card_answers`와 `check_per_unit_dialogue` 기존 시나리오 31개 통과. 자산/DB 서비스 초기화와 유지보수는 제외하고, DB·모델 연결을 비운 격리 래퍼로 실제 API 라우트·체크포인트·Excel 응답을 검사했다. 처음 실행한 전체 검사는 Windows asyncio 소켓 제한으로 대기해 중단했으며 전체 통과로 집계하지 않았다.
- API 검사에서 일반 조건 30회 무료/31번째 차감, 현재 ref 검증, 작업 범위·새 견적 등의 유료 예외, 중복 요청 처리와 비회원 Excel 파일 응답 확인.
- 별도 로컬 모의 서버로 PC 선택 강조·확정 전 안내·일반 조건 안내, 모바일 한 열 배치·로그인 혜택/비회원 Excel 안내 확인. 운영 모델 호출과 실제 사용자 사용량 차감은 0회.

### 확인한 정책 근거

- `backend/api/dialogue_service.py:free_card_answer`: 현재 pending ref 일치, 30회 제한, 새 견적/작업 범위/이어가기 등의 유료 예외.
- `backend/api/main.py:chat`, `_member_chat`: 요청별 무료 판정 후 기존 차감 처리.
- `backend/api/main.py:export_xlsx`: 비회원은 guest secret과 유효한 임시 대화로 접근하며 최신 확정 견적을 내려받는다.
- 현장 관찰의 작업 범위 확정 3→2와 다음 공종 선택 2→2는 서로 다른 종류의 요청이다. 이 관찰만으로 차감 버그라고 단정하지 않는다.

## 2단계 — /guide 최소 버전 (미진행)

1. 견적·품셈 상담의 차이와 지원 범위.
2. 질문 작성 예시와 /chat?q= 연결(직접 전송).
3. 작업 범위 선택 → 공종/조건 확인 → 확정 전송의 순서.
4. 금액·미산정 항목·가정·근거/원문 확인 방법.
5. 이용 횟수·로그인 저장·임시 대화·Excel 안내.

검증된 화면과 사례만 사용하고, 다른 LLM이 확인하지 못한 기능은 오프라인 검증/실제 화면 검증의 근거를 구분해 기재한다.

## 3단계 — 공개 연결·검색·전환 검증 (미진행)

- /guide 전용 라우트, 고유 제목·설명·canonical, 정적 HTML과 sitemap 반영.
- 홈·채팅에서 가이드 링크 제공. 알 수 없는 경로의 홈 대체 동작과 분리.
- 모바일·키보드·링크·예시 미전송 확인.
- 가이드 열람 → 채팅 진입 → 첫 질문 전송 측정 방안 마련. 기존 개인정보·수집 거부 정책 유지.
- 검색 색인/노출은 Search Console로 추적하되 노출·순위 효과를 보장하지 않는다.
