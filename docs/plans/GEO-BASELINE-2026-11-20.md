# GEO 우선 진행: 기본 정리와 후속 과제

사용자 요청에 따라 사용 완주 검증보다 GEO의 기본 점검·개선을 먼저 진행한다. 사이트 내 공개 자료를 검색/AI가 읽을 수 있게 정리하는 작업이며 노출·인용·추천 증가를 보장하지 않는다.

## 확인과 반영

- robots.txt는 공개 홈·가이드·예시 수집을 허용한다. 채팅·API·인증·시험 경로 차단은 유지한다. 특정 AI 봇 그룹을 별도로 추가해 기존 경로 제한을 우회시키지 않는다.
- 운영 홈·가이드·예시는 OAI-SearchBot/1.4 User-Agent로 보낸 일반 HTTP 요청에 200과 사전 렌더된 HTML을 반환했다. 실제 OpenAI IP 접근이나 CDN의 모든 봇 정책, 실제 수집·인용 여부를 확인한 것은 아니다.
- 홈페이지에 서비스 정의, 로그인 없이 이용 가능한 범위, 질문에 필요한 정보, 견적 사용 한계를 담은 FAQ 4개를 추가한다. 사용 가이드·질문 예시로 연결한다.
- 공개 HTML의 WebSite·WebApplication·WebPage JSON-LD를 일관된 이름·서비스 설명·공식 주소로 연결한다. 설명은 화면의 FAQ와 같은 소스를 사용한다. 확인되지 않은 회사 정보·작성자 자격·리뷰·평점은 넣지 않는다.
- 기존 고유 제목·설명·canonical·OG·사이트맵과 공개 페이지의 사전 렌더를 유지한다.
- llms.txt는 이번 범위에 넣지 않는다. Google은 검색(생성형 기능 포함)에 사용하지 않으며 노출·순위에 영향을 주지 않는다고 설명한다. 다른 서비스에서의 효과도 확인 없이 주장하지 않는다.

## 검증

- 프론트 테스트 14개 스위트·121개 통과.
- 공개 HTML 검사: JSON-LD가 유효한 JSON이며 각 페이지의 대표 주소와 연결되고, 서비스 설명이 실제 홈페이지 HTML에도 존재하는지 확인.
- 공개 FAQ의 화면·키보드 펼침 동작, 빌드·운영 HTML 확인.
- 최초 파일 기록 중 C드라이브 여유 공간 부족 발견. 이 프로젝트의 재생성 가능한 `frontend/node_modules/.cache`만 절대 경로 검증 후 정리했다. 사용자 소스·문서는 정리 대상에서 제외했다.

## 다음 우선순위

1. 검증된 실제 품셈 질의 2~3개를 선정해 공개 설명 콘텐츠로 작성한다. 적용 조건·포함/미포함 범위·근거 절/쪽수·검토 시점을 제시하고 가이드/서비스에 연결한다. 아직 근거를 검증하지 않은 금액이나 규정을 생성해 게시하지 않는다.
2. Google/Bing 검색 관리 도구의 실제 색인·노출과 공개 콘텐츠의 유입을 확인한다. 검색어와 페이지 데이터를 바탕으로 주제를 보완한다. 현재 자료만으로 AI 추천 빈도나 시장 검색량을 추정하지 않는다.
3. ChatGPT 등에서 질문별 인용 여부를 표본 관찰하되 계정·지역·시점에 따른 변동을 고려한다. 특정 브랜드 검색만으로 일반 질문에서의 노출을 입증했다고 보지 않는다.

## 공식 근거

- [Google 생성형 검색 최적화 안내](https://developers.google.com/search/docs/fundamentals/ai-optimization-guide): 유용한 고유 콘텐츠·기본 SEO 중심, llms.txt와 별도 AI 마크업이 필수 아님.
- [OpenAI 크롤러 안내](https://developers.openai.com/api/docs/bots): 검색용 OAI-SearchBot과 학습용 GPTBot 등의 목적을 구분. robots 허용만으로 실제 IP 접근이나 검색 노출을 보장하지 않음.
