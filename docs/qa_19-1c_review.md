# 상담 답변 1차 채점 수정

`eval_qa.py`는 `resolve_cites()`가 만든 표시용 부문 값과 정답 부문을 비교했다.
실제 `p368-t0` 청크의 부문은 `토목`, 절은 `1-5-4`지만 인용 라벨을 만드는
페이지 맵의 부문은 `토목부문`이어서 `draft-2460`도 False로 판정되었다.

수정한 판정은 원본 청크의 `(division, section_no)`가 정답과 같거나,
comparisons/결론에 정확한 `부문 절` 문자열이 있으면 True다. 다른 부문이나
`1-5-40`처럼 절 번호가 더 긴 표기는 정답으로 인정하지 않는다.
표시용 인용 라벨과 기존 채점 결과 파일은 수정하지 않았다.

실제 답변 품질과 지연 개선 수치는 검토자의 재채점으로 확인해야 한다.

## 적용한 변경과 검증

- 표 인용은 공백·구분자·저장용 머리글을 정규화하고, 불일치하면 줄 단위
  `SequenceMatcher` 일치율 0.85 이상에서만 허용한다. `quote_match: "fuzzy"`를
  기록하며 표시할 인용은 해당 원문 줄로 교체한다.
- 숫자는 원문과 질문에 있는 값만 허용한다. 금액과 잘못된 절 번호 검사는 유지한다.
- 대체 답변은 절 제목을 제외한 내용 행을 질문 낱말 겹침으로 고르고 중복을 제거한다.
  화면에서는 후보 절 아래에 원문 행과 원문 보기 버튼을 한 번 표시한다.
- 기본 모델은 `gemini-3.5-flash-lite`를 유지했다. LLM 요청·재시도 상한은
  12초, 문맥은 절당 4,000자다. 검색 시간은 LLM 상한에 포함되지 않는다.
- `run_quick.py` 19개 스크립트 통과, `check_qa.py` 45/45 통과,
  `npm.cmd run build` 성공. 기존 라우터·견적·API 기대값은 변경하지 않았다.
- `.env`를 읽거나 외부 LLM을 호출하지 않았다. 기존 실제 채점 결과는 보존했다.

## 검토자 재채점

```powershell
$env:AGENT_LLM='on'
$env:AGENT_OFFLINE='0'
$env:PYTHONIOENCODING='utf-8'
.venv/Scripts/python.exe evals/eval_qa.py --model gemini-3.5-flash-lite
```

같은 날짜에 실행하면 해당 날짜의 모델 결과 JSON과 사람 검토용 모델 섹션을 갱신한다.
