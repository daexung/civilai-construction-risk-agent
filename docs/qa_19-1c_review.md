# 상담 답변 1차 채점 수정

`eval_qa.py`는 `resolve_cites()`가 만든 표시용 부문 값과 정답 부문을 비교했다.
실제 `p368-t0` 청크의 부문은 `토목`, 절은 `1-5-4`지만 인용 라벨을 만드는
페이지 맵의 부문은 `토목부문`이어서 `draft-2460`도 False로 판정되었다.

수정한 판정은 원본 청크의 `(division, section_no)`가 정답과 같거나,
comparisons/결론에 정확한 `부문 절` 문자열이 있으면 True다. 다른 부문이나
`1-5-40`처럼 절 번호가 더 긴 표기는 정답으로 인정하지 않는다.
표시용 인용 라벨과 기존 채점 결과 파일은 수정하지 않았다.

실제 답변 품질과 지연 개선 수치는 검토자의 재채점으로 확인해야 한다.
