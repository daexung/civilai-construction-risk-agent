# 품셈이 랜딩 화면

디자인 기준: [사용자가 지정한 Lovable 화면](https://preview--screenshot-magic-6503.lovable.app/) (2026-10-06 실제 화면 확인).

## 적용한 구성

- 원본의 흰 배경, 좌측 정렬 제목, 녹색 계열 색상과 간격을 기준으로 구성합니다.
- 큰 두 줄 제목(데스크톱 72px), 반경 8px 버튼, 본문 최대 폭 1152px을 유지합니다.
- 견적 예시는 원본처럼 질문/금액 2열(1:1.35)이며 모바일에서는 세로로 배치합니다.
- 결과는 요약 금액과 내역을 먼저 보여주고, 계산 과정과 적용 근거를 펼쳐 확인합니다.
- 이용 방법, 구분선이 있는 가로형 기능 목록, 짙은 녹색 마지막 시작 영역을 원본 구성에 맞춥니다.
- 문구와 기능은 품셈이의 공사비 견적, 품셈 상담, 엑셀 출력에 맞췄습니다.
- 저장된 실제 응답 `demo.json`을 사용합니다. 계산 과정을 펼치면 원가계산서·일위대가·산출근거 탭을 조작할 수 있습니다.
- 예시가 부분 금액임을 표시하고 실제 미산정 항목과 원문 출처를 제공합니다.
- 시작은 기존 `/chat`, 예시 질문은 기존 `onExample`에 연결합니다.

## 검증

- 프로덕션 빌드 성공.
- 랜딩 테스트 2개 통과: 기능 소개, 계산 과정 펼침, 결과 탭·키보드 조작, 채팅 시작과 예시 질문 연결.
- 브라우저에서 320px, 390px, 768px, 1280px 화면 너비의 가로 넘침 없음 확인.
- 브라우저에서 계산 과정·근거 펼침, 결과 탭 전환, 시작 → `/chat` → 뒤로가기 확인.
- 요약 내역의 합계 10,032,436원이 저장된 응답의 도급액과 일치함을 확인.
- 실제 API를 통한 질문·조건 선택·계산과 엑셀 생성, 원문 보기까지 확인했습니다.
- 렌더링 캡처: `docs/ui-lovable/landing-desktop.jpg`, `docs/ui-lovable/landing-mobile.jpg`.

화면 검토: http://127.0.0.1:3000 (개발 서버 또는 API 프록시를 연결한 프로덕션 빌드).
